# V5 零点与传动对接规范（链传动 1:1 独立驱动）

核对日期：2026-09-26。面向 RMCS `rmcs_rl`、底盘硬件适配及标定人员。
本文对齐一项已确认的机械事实，并给出与之配套的零点、符号、映射的标定规范。

- **机械事实（已由机构行为确认）**：髋/膝电机同轴嵌套布置，**定子均固定于底盘**，
  各经 **1:1 链条**独立驱动主动杆（大腿）与从动杆（小腿）。
  保持大小腿夹角不变做整杆摆动时，两台电机编码器同步同量转动——这是**闭链几何的协调**，
  不是机械差动耦合。锁住大腿动小腿时只有膝电机转。
- **推论**：状态解码与命令编码使用**独立线性映射**（对角 ±1 + 偏置）即可，
  **不含髋角差动项**。结构成立的前提是完成本文第 5 节的符号与零位标定。

## 1. 坐标系与数组顺序

```text
P = [L_joint1, LL_joint1, R_joint1, RR_joint1, L_joint3, R_joint3]   ONNX 观测/动作、RMCS 缓存
C = [L_joint1, LL_joint1, L_joint3, R_joint1, RR_joint1, R_joint3]   仿真 manifest/V5Control
D = [left_hip, right_hip, left_knee_drive, right_knee_drive]         硬件 DM 参数数组
```

D 既不是 P 的前四项也不是 C 的前四项。功能映射（P/C/D 索引）：

| 功能 | 关节 | P | C | D |
|---|---|---:|---:|---:|
| 左髋（主动杆电机） | `L_joint1` | 0 | 0 | 0 |
| 左膝（从动杆电机） | `LL_joint1` | 1 | 1 | 2 |
| 右髋 | `R_joint1` | 2 | 3 | 1 |
| 右膝 | `RR_joint1` | 3 | 4 | 3 |
| 左轮 | `L_joint3` | 4 | 2 | —（M3508） |
| 右轮 | `R_joint3` | 5 | 5 | —（M3508） |

电机在底盘上的**前后安装位置不构成重排依据**；链绕向也不改变关节命名。
`L_joint2/R_jonit2` 及 LLL/RRR 系是闭链被动铰，不是策略或电机的直接坐标。

## 2. 三层零点定义

| 层 | 定义 | 数值来源 |
|---|---|---|
| L1 电机编码器零点 | 驱动器上电/设零时编码器读数为 0 的姿态 | 实车标定（本文第 5 节） |
| L2 URDF 装配零位 | CAD 导出姿态，各关节坐标 θ=0；此时气簧压缩 74.53mm | `robot.urdf` 各 joint origin |
| L3 训练名义零位 | 策略观测与动作解码的基准姿态；机体高 0.32m、气簧压缩 56.9mm | manifest `nominal_joint_pos` |

换算关系：`L2 = L1 + 标定偏置`（每轴一个常数偏置 + 方向符号）；
`观测 Δq = q_L2 − q_L3`，其中 q_L3 = q_L2 + nominal（nominal 见第 3 节）。
**部署时 nominal 必须使用交付包 control_prior 数值，不得自定义站姿。**

## 4. 映射公式（独立线性，1:1 链）

```text
状态解码（电机 → 模型）：
  q_model[i]  = s[i] · (e[i] − z[i])          i ∈ 四 DM 轴；s[i]=±1，z[i]=L1 零位偏置
  q_wheel[i]  = s_w[i] · e_wheel[i]
  dq 同公式（对速度先做连续角解缠，见自起文档 §4.1）

命令编码（模型 → 电机）：
  e_cmd[i] = z[i] + s[i] · q_target[i]
```

`s/z` 的四组值来自第 5 节标定，随 YAML 版本管理；**不得使用零矩阵占位启用控制**。
轮侧另有减速比待统一项：实车配置 15.8，训练包络先验 11——标定时以实测输出端为准，
训练包络的更新走合同变更，不允许把一个数值当成另一个参考端已标定。

## 5. 标定流程（逐级，前级未过不进后级）

1. **符号标定**：断电状态下把腿摆到一个已知姿态（对齐量块/样板），上电读编码器；
   手动正转髋电机（正方向定义为使大腿向前摆），记录编码器符号——确定 s_h；
   同法锁髋动膝确定 s_k。左右两侧分别标定，不假设互为镜像。
2. **零位对齐（z）**：将机构摆到 URDF 装配零位姿态（用量块/工装对齐各连杆基准面，
   气簧压缩应为 74.53mm——可作为零位是否正确的机械验证），读编码器并记 z[i]。
   此后 nominal 姿态的编码器读数应等于 z[i] + s[i]·nominal[i]（允许 ±0.005rad）。
3. **比例核验（k=1:1 确认）**：髋不动，膝电机转整圈，从动杆应转整圈（±方向按 s_k）；
   若从动杆转角与电机角比例偏离 1:1 超过 0.5%，链轮齿数假设错误，回到图纸核对。
4. **瞬时功率校验**：慢速摆腿记录 `tau_model^T·dq_model` 与 `tau_api^T·dq_api`，
   两者应同号且量级一致（差异部分即摩擦/损耗模型，另行建模）。
5. **连续圈数**：髋连续旋转越过 ±π 时验证解缠（自起文档 §4.1 的累计式），
   验证"锁髋动膝"时膝编码器不受髋运动干扰（独立性的最终实测确认）。
