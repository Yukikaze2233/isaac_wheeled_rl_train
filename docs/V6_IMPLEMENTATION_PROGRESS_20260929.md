本轮已经执行离线辨识与新资产检查，不是新的正式训练成绩。网络保持 actor35 / critic81、MLP 256/128/64、ELU、六动作。正式 S1–S6 仍须等执行器模型、课程合同和验收入口冻结。

## 华南虎方法的实际复用

依据[系统辨识原文 §4.2](https://bbs.robomaster.com/article/1942489?source=1)与固定源码 `b8ff79f3df855faf9dc92f4a282bd80c42649466`：轮侧拟合摩擦/阻尼，腿侧在架空、完整并联机构中重现预设轨迹和闭环，再对比真机曲线。此源码快照提供执行器和限矩函数，没有发现可直接调用的 bag→整腿参数优化器。

因此复用本项目已有 MuJoCo 闭链回放，整理为 `scripts/identify_pair_dynamics.py`；同侧髋与膝驱动共同仿真，保留轮子、被动关节、重力和气簧。每段只在起点使用实测初态，其后自由积分，未逐帧写入实测位置。PD 160/2.5 固定，每 1ms 重算；50Hz 目标直接取录制值保持，不调 PD 补偿动力学误差。

关键反证是**1秒实发力矩输入回放仍有明显偏离**，平均分段角 RMSE 约1rad。强 PD 闭环会抑制模型误差，闭环曲线比较接近不足以确认真实被控对象。静态共同方向力矩也与 CAD 重力预测存在系统残差。扭矩比例消融、静载/摩擦与编码器参考零位应分别检查，禁止把候选直接发布到训练。

扭矩比例消融已完成：左/右候选比例约1.291/1.207。左髋闭环误差降至0.01645rad，但左膝反升至0.02228rad；右侧约0.01906/0.01957rad。两侧力矩输入回放反而恶化到平均约1.7–1.9rad，拒绝用这两个比例修补模型。它们不是实测电机力矩标定值。最终主动阻尼已对齐的新资产再次执行1ms留出，结果与候选物理资产对应结果一致。

软件链排查未发现大的比例/符号错误：记录的纯PD代数逐点一致；模型角与API角映射残差不超过4.44e-16rad；发帧量化差最大0.01319Nm，符合±54编码半步。54是协议定标，40是软件峰值限幅，代码没有乘40/54。现有包没有电机实际T_MAX寄存器回读；不能把“峰值40”直接推成“编码也应40”，也不能借同一编码尺度的DM反馈估计力矩作独立测力证明。

共同运动的虚功力矩是两主动轴力矩之和。理想气簧对此方向的投影小于8.7e-5Nm，不能靠调气簧幅值直接消除共同方向残差。近同一姿态左侧三个停留段的名义发出力矩和约−8.20/−4.80/−4.66Nm，CAD预测均约−2.43Nm，说明进入方向/历史必须分组；单点静载比值不能用于反算电机gain。当前停留筛选只要求速度RMS<0.08rad/s，没有证明完全静止或无止挡接触。

IMU 以运行段每100个样本诊断：左/右相对水平平均倾斜约3.23°/2.48°；IMU坐标→CAD安装对齐仍未独立确认。架台不是完美水平常量；该记录只用于有出处的重力姿态对照，不允许任意旋转曲线去追求重合。

反馈时间也有左右差异：右包约8.1%的控制样本重复上一feedback sequence，反馈年龄p99约1.69ms；左约0.72ms。补充的左右79/89段对照只在记录seq重复时保持仿真q/dq反馈，物理仍自由积分、每1ms继续计算PD。固定现有六参数后，角RMSE变化最多约4.3e-6rad，说明单独的重复帧保持不是当前残差的主因。host反馈时间是回调接收时刻，不能唯一还原电机真实采样时刻；本对照未模拟未知采样延迟，也未分离FOC，拟合lag仍为合成响应。该动态差异不解释静态共同方向残差。

独立[零位与静载几何核对](../reports/v6_zero_pose_audit_20260929/README.md)进一步确认：API零位在新V6的内角为左105.0217°、右105.0212°，大腿朝上；对应静载初态却是106.9841°/105.7330°。名义缺失反力大部分与阻止膝继续张开的止挡反力方向一致，因此近零提交力矩不能直接推成气簧力小。尚须确认真实上止挡、标定精度和加载变形，不能直接把资产110°改成105°并把被约束拉回的轨迹算作辨识成功。原静载诊断 getter 在切向差分后残留1e-5rad扰动态，造成约0.0005°内角偏差；脚本已恢复原姿态，并通过24项辨识测试。历史报告原样保留，动力学拟合不受此getter修正影响。

## 轮侧发现

轮输出单位只做一次15.8转换，速度环工程选择仍为P0.6。现有运动摩擦/阻尼拟合不能解释低速停走；引入固定静止阈值虽改善部分±0.2rad/s段，仍漏掉短暂滑动和持续停走，且右轮滑行有退化。不能把拟合的动摩擦截距叫已辨识静摩擦，更不能将速度控制增益当物理黏滞阻尼。

详见 RMCS `docs/zh-cn/artifacts/wheel_speed_v2/scut_real2sim_audit_20260928/README.md` 与对应脚本/JSON；静止阈值搜索范围是损失平坦区域，不是统计置信区间或物理硬界。
