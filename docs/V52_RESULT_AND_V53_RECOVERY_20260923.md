### 华南虎的两个名称实际表示什么

核对本地SCUT参考源码：

- `wheelbipe25_v3/env.py:3573-3582`：`stand_still_deadzone`判断的是**指令幅值**，小指令归零；不是测量轮速的免罚区。
- 同文件3748-3751行：`stand_still_lin_vel = (abs(vx)+abs(vy))*stand_still_lin_mask`，是**机体线速度L1惩罚**。
- `wheelbipe_V14/env_cfg.py:901`配置该项权重−1；它不包含当前位置与初始位置之差。

我们当前`rewards.py::reward_terms`已有`stand_translation`，V5.2静止组再乘3；
`StationaryAnchor`另外提供`-(1-exp(-distance²/0.1²))`的位置驻留惩罚，二者都实际进入训练日志。
因此“只抄死区、缺少线速度或位移项”不是V5.2现状，往合同里放一个未被环境读取的同名key也不会自动产生新reward。

## 3. 已证实的机制问题与尚未证明的原因

1. **优化步长比名义起点更激进**：第一块LR最高3.844e-4，约为起始5e-5的7.7倍；均值1.285e-4。
   critic预热期固定LR修复生效，升高发生在后续自适应阶段。
2. **迁移探索显著增大**：原actor四腿std约0.023–0.028，统一抬至0.08，相当于约3倍。
3. **已学能力保护缺失**：flat没有前序阶段，所以所有固定案例`anchor=false`；整套基线又未通过，
   且integrated合同强制`regression_patience=None`。因此18/27→0/27没有触发停止。
4. **奖励／难度与采样同时改变**：各组核宽、倍率和自旋上限独立变化；约40%的样本覆盖已通过案例对应组。
   这些因素与退化相容，但当前联合实验不能拆出单因素因果效应，也不能把它们统称为气簧的固有漂移。

## 4. V5.3接续方案

执行计划：`contracts/v5_scut35_repair_v53.json`，从原始12486候选迁移actor。
V5.2产物保留作对照，不恢复其退化后的优化器与课程状态。

- 所有阶段使用固定LR **3e-5**；每阶段新critic和优化器，前50次实际更新只训练critic。
- 初始探索std下限降到 **0.03**，保留原本更大的轮部std。
- 基础修复恢复固定默认高度核`sqrt(0.001)m`和倍率1，保留平方项；关闭核宽／权重／自旋上限性能课程。
- 保留低／高高度训练、方向分组、驻留锚点、零速惩罚和100ms训练fall确认；固定评测仍是原判据。
- **50%采样显式排练已学技能**：16个训练组覆盖原有18个通过案例，其余50%用于修复组。
- 将上述18个案例标成anchor，启动时必须复验通过。每250次实际更新评测；连续2次失去anchor则停止。
  这一保护也对同合同optimizer resume生效，不依赖本进程是否重新执行了初始基线评测。
- 后续阶段恢复有限回归保护；原固定案例目标、精度、漂移门与机械约束不放宽。
- 保留七阶段预算：4000 / 2000 / 3334 / 3334 / 3334 / 5334 / 4000，共25336次实际更新，最长7天。

这是保守的联合回退实验，目标是先保持原有能力再修复短板，不是已经证明最优的奖励或超参数。
若第一次250更新已有退化，应看`failed_anchor_cases`、原始误差与终止原因；不能等到全部预算结束才发现能力丢失。

## 5. 验证与部署顺序

1. 回归测试验证固定学习率、50%排练、案例阈值不变、初始anchor检查、续训后的anchor保护。
2. 展开6144环境合同并运行固定奖励形状审计。
3. commit后用同一版本运行64环境60次工程短测，确认50次critic预热、10次actor更新、导出和回收。
4. 从该commit部署6144环境完整队列，检查实际worker和首个恢复快照；运行身份、commit和SHA写入部署回执。

本轮不修改漂移门。若未来上层定位闭环确实改变任务需求，应单独定义并验收分层控制方案，而不是倒推门槛使现有策略通过。
