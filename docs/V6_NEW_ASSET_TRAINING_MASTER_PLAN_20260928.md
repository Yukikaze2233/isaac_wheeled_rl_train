## 2. 机械事实、bag 与辨识边界

四个主动轴 `L_joint1/R_joint1/LL_joint1/RR_joint1` 均连续转动：URDF continuous、MuJoCo limited=false、USD 无位置限位。**大腿主动轴无机械限位，40–105°是被动膝/大小腿相对内角的名义范围**。用户确认105°为标定及止挡角，106/107°可来自零偏、变形或公差；不能把该相对角当单个电机角截断。

同侧两主动输出等增量产生共同摆腿，差动改变膝角；q/dq/力矩统一按新坐标映射。气簧保留232mm全伸销距、80mm行程及既有10MPa拟合，通过机构力臂施力一次。总质量13.886kg，RR_link2采用CAD的0.084kg；独立称重仍待完成。

**打到止挡的 bag 可用**：划分自由运动、接近、持续接触和脱离。自由段约束电机/传动响应；接触段约束止挡、零偏和顺应性；脱离段帮助检查静摩擦与预载。联合模型需显式接触/反力，不把止挡反力拟合成电机阻尼、扭矩比例或气簧增益。当前 bag 膝内角约100–107°，不覆盖全40–105°域。

复用[华南虎系统辨识 §4.2](https://bbs.robomaster.com/article/1942489?source=1)：轮侧识别摩擦/阻尼；架起车体、完整腿机构髋膝同时执行预设轨迹，在 MuJoCo 重放同一控制目标、保留重力与气簧，通过真实/仿真曲线调物理参数。固定源 `b8ff79f3df855faf9dc92f4a282bd80c42649466` 未发现可直接使用的整腿 bag 优化器，也没有“碰限位数据全部作废”的规则。源码中的动作角裁剪不是大腿机械止挡。具体核对见[连续轴与止挡数据](V6_CONTINUOUS_AXIS_AND_STOP_DATA_20260929.md)。

左右160/2.5与轮P0.6是实机控制器工程选择。[11包总结](V6_BAG_SUMMARY_20260928.md)、[条件拟合与130项止挡对照](V6_IMPLEMENTATION_PROGRESS_20260929.md)保留原证据：条件拟合改善部分闭环曲线，但不能同时解释实发力矩回放与静载。因此本次**不注入尚未发布的六参数候选**，不把拟合lag称USB延迟。使用标明来源的CAD/气簧/驱动工程先验与随机化开展仿真研究；候选模型、G1和实车发布保持未通过。

温度、老化、长时间低气压与未知FOC内部状态未纳入已验证模型；本轮不宣称覆盖。S3的单侧降额是episode恒定工程扰动，不等价于真实热衰退曲线。后续G1用跨构型、跨方向、跨频段及独立新运行留出，再做同轨迹Isaac核对；禁止随机拆帧造成泄漏。

## 4. 稠密 reward 与动态参考

全阶段使用同一冻结基形；动态性来自可部署的命令参考、加减速和技能相位，不通过隐藏难度随意改变核宽。普通高度不惩罚actor不可见的高度导数；人工STEP/JUMP请求，不引入前向地形传感器、raycast自动触发或接触真值泄漏给actor。

各误差使用持续区分大误差的负pseudo-Huber广域项，加默认开启的Gaussian精核成本；两者均乘可解释的任务/支撑门。零误差处解析导数为零不代表PPO梯度饥饿，学习要由采样优势与实际行为判断。

|误差|广域尺度/权重|精核尺度/权重|
|---|---|---|
|高度|0.04m / 3.0|0.015m / 1.5|
|前向速度|0.5m/s / 2.0|0.10m/s / 0.6|
|侧向速度|0.15m/s / 0.5|0.08m/s / 0.25|
|yaw速度|1rad/s / 1.0|0.2rad/s / 0.35|
|静止平移速度|0.1m/s / 1.5|0.04m/s / 0.75|

驻留与运动奖励通过命令可见的连续门混合，避免硬阈值跳变。旧precision与旧跟踪项不重复叠加。力矩、功率、动作变化、姿态、碰撞与闭链成本保留明确量纲；蹬伸相位有显式软成本缩放。死亡事件成本200，正常成功事件+5且序列中每次成功只付一次；时间截断保留bootstrap语义。

定标已执行12组固定合成轨迹反例：半速、过速、站高上漂、驻留侧滑、动态高度不跟随、启停滞后等，检验完整折扣回报排序、广域/精核衔接以及早死获利。结果见[奖励冻结](V6_REWARD_FREEZE_20260929.md)。合成反例不是物理可达性或PPO学习保证；首40更新及逐块固定评测检验实际行为。

P0 A/B证据作为定标输入：去饱和改善静止漂移，却未恢复高度响应与总通过数，且前进过速加剧；禁止再叙述成“持续半速”。[失败分析](V6_CURRICULUM_FAILURE_ANALYSIS_20260928.md)保留高度—速度联合过冲、命令/力矩时间线及优势分组诊断。静态实车FK高度、断能平衡高度、重力与气簧对照仍属于G1证据，不靠reward修几何偏差。

## 6. 时钟、状态恢复与验收

课程随actor更新推进，episode重置不清零；没有基于单回合成功率的自动难度反复进退。保存 `stage_actor_update`、跨阶段offset、全局学习时钟及累计消费计数。回滚恢复checkpoint课程时钟，已经花掉的actor/critic更新继续计预算；“112更新checkpoint、已消费312”保留两套数字。确认bin通过记录是独立评测账本，不是隐式改reward。

同合同恢复actor/critic/Adam与已保存课程/RNG状态；仿真episode重建，不声称恢复物理世界的逐位状态。跨阶段显式只继承actor+critic权重、重新初始化optimizer。每个checkpoint旁保存文件hash、合同hash、课程clock与消费/学习谱系；封存状态、gate结果、checkpoint角色分开，hold/best_preserved不会导致封存文件无法识别。

每40更新及阶段末使用**完整239用例**，本次“quick”也不裁剪名单。S1–S5每case4回合，S6每case20回合；初始随机策略的0更新checkpoint建立两个seed基线，候选需要独立seed290930确认。基线、候选、确认均包含所有USB和组合名；缺必需项返回 `invalid_evaluation_coverage`，禁止晋级。

默认门槛：存活/成功≥95%，高度MAE≤1cm，平移MAE≤0.1m/s，yaw MAE≤0.15rad/s，驻留速度≤0.03m/s、漂移≤0.1m、倾角≤20°；具体case附加动态过程与机械条件以冻结JSON为准。S1–S5的4回合意味着该门槛实际要4/4，不宣称高置信成功率估计；最终每seed20回合也只是验收样本。

S6请求用例必须记录事件实际送达、接受/重复/取消计数、取消所在真实相位、重复是否错误重置时钟、完成跳数，以及移动/驻留/恢复移动的跟踪时长。普通jump success不能替代这些条件。第二跳重新建立释放/顶点记录；无伪造phase或直接写姿态。

阶段保护失败回滚有界重试一次、LR乘0.5，消费不退；预算耗尽或必要覆盖缺失保留best并停止，不能自动跳过阶段。这是一条按验收推进的完整链，不是承诺所有技能一定在一次运行学会。

用户再次明确要求保留延迟、负载、质心等域随机化。本节核对实际物化合同及实现，不改变已冻结的运行合同。当前接续采用 `contracts/v6_wheel_response_training_v1.json`，部署源 `5bde97f`，回执见 [轮侧接续](V6_WHEEL_RESPONSE_LAUNCH_20260929.md)。两轮采用已验证的惯量/运动阻力，腿仍用名义先验。新旧六阶段的 dynamics/command transport/USB/contact/signal 配置逐项完全相同。

**启用时机：S1/S2训练使用名义域；S3–S6启用以下扰动。** 固定评测在各阶段保留明确的轻重载、COM、通信及组合用例；训练开关和评测开关不能混读。旧 `mass_randomization_enabled:false` 不控制本轮刚体随机化；实际由 `dynamics_randomization.enabled` 控制。旧 `usb_transport` 保持关闭以避免与新下行模型重复计时，不等于所有阶段无通信扰动。

|项目|当前冻结范围和生效方式|
|---|---|
|固定载荷近似|base_link质量0.9–1.1倍；腿/轮质量保持1倍。惯量随对应质量同步缩放，额外独立惯量倍率为1。按环境启动抽样并保持，不逐步重抽|
|质心|base_link局部x±10mm、y±5mm、z=0；通过物理后端写入并读回，不能称整车质心直接平移同样数值|
|地面摩擦|有效摩擦0.3–1.2，保留名义0.5；与质量/质心、通信复用约50%环境的扰动分组，另一半保留名义对照|
|命令下行|0.04–0.16ms工程先验，1ms CAN取最新已到命令；训练丢包与burst概率为0，不声称训练过非零丢包|
|传感噪声、执行器与气簧|约50%扰动环境内再按episode抽50%，故总体约25%；六轴力矩系数各自0.85–1.0，左右气簧共享0.9–1.1倍率。episode内保持，不能笼统称全部50%|
|单侧持续降级|另有5% episode将随机一侧三轴力矩乘0.5，episode内恒定；与上项可叠加|

这些质量、COM和缩放值仍是工程先验，不是由悬空电机bag识别出的载荷分布。独立惯量和新辨识轮侧armature/摩擦目前固定；现有强度倍率不能冒称所有执行器响应参数都已随机化。

需要补齐的范围明确保留：

1. **实际载荷组合**：空载/满载及上装位置对应的质量、三维COM和惯量须成组给定；用等效刚体时保持物理一致性，不能随意独立拼出不可能组合。当前z质心没有扰动，也未模拟移动上装、弹药消耗或装载变化过程。
2. **传输与反馈时序**：USB-HS RTT、主机调度、CAN交付、反馈采样/年龄、电机本体响应分开记录，避免重复叠加。实际CPU探针确认0.04/0.08/0.12/0.16ms在当前同步1ms CAN模型中输出相同，均下一tick生效；这覆盖一拍命令保持，未精确表达亚毫秒抖动。反馈延迟未单独校准，`max_delay_steps=0`，不拿50Hz的一帧20ms代替。
3. **辨识模型的不确定性**：以跨轨迹/重复试验的残差和参数相关性确定可接受集合，优先对真实参数组合取样；不任意给每项±20%。温度、老化和持续泄压仍不属于已验证模型；左右气簧共享倍率还不能覆盖左右独立压差。
4. **验收**：名义、单因素和未训练组合分别评分；记录实际随机化分组占比、质量/COM/native参数读回、执行命令年龄和采样种子。S1的20k名义场景探针不能充当S3全部扰动的GPU验收。当前固定评测关闭signal扰动，239用例尚无命名的motor/spring/degradation专项，因此训练中出现这些扰动也不能冒称已经完成其固定验收。

后续若扩大范围或修订通信时序，需要新合同及同检查点对照，再按迁移协议计账复习；不热改运行进程，不将这些待完成项写成已经启用。
