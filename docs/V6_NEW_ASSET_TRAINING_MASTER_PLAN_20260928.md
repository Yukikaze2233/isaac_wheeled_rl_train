### 动态、稠密、有区分度的具体形式

“动态”指参考随命令和动作阶段变化，不是在线任意改变奖励核。统一参考由实际送入策略的命令及命令时钟产生；`vx_ref, yaw_ref, h_ref`和技能过程量与现有接口保持一致。`ax_ref/h_dot_ref`可先用于命令生成、可达性与诊断；启用它们驱动奖励须先通过上述35D可辨识性检查，不能为了动态奖励暗改网络输入。轨迹速度/加速度由辨识后的可达域限制，不能让PPO追踪物理上做不到的蹬伸。

对误差`e`，推荐候选基形为：

```text
rho(e/s) = sqrt(1 + (e/s)^2) - 1
r_track  = -w_broad * rho(e/s)
           + w_fine * expm1(-(e/sigma_fine)^2)  # Default on for precision behaviors
```

`s`、`sigma_fine`与误差单位相同。广域平滑损失在大误差区近似线性，精核增加接近目标时的分辨率。`rho≈e²/(2s²)`而`d rho/de≈e/s²`：损失二次趋零、导数线性趋零；Gaussian精核在零误差的导数也为零，它提高局部曲率，不能保证PPO无“梯度饥饿”。PPO的有效学习仍由采样优势和策略更新验证，解析斜率不代表网络一定获得有用梯度。

精核默认项仍须定标：按实际误差覆盖和测量噪声选择尺度、冻结非零权重，并验证广域项与精核交接没有学习信号薄弱区；不可只把宽度设成验收容差。对高度10→5mm、速度误差0.10→0.05m/s及半速/过速回目标分别计算完整回报差，并对照姿态、平滑和力矩成本。精核可在大误差区饱和，但广域项必须继续区分改善；不随意clip广域误差成常数，也不在某误差阈值外突然关闭负精核，避免逃出精度区反而得益。此处选`expm1`沿用现有有界负精度成本；它与`exp`虽导数相同，回合长度/终止可变时累计回报不同，必须连同下述终止反例校验。

|动作过程|每个策略步评价什么|反例必须得不到相同收益|
|---|---|---|
|静止/升降|`h-h_ref`、平面速度及yaw、姿态；`vz-h_dot_ref`仅在现有接口可辨识时启用|固定中位站姿；升高达标但持续漂移|
|加速/刹车/反向|`vx-vx_ref`、`yaw-yaw_ref`、现有可见参考对应的姿态目标；停车后转入零速目标|半速或过速；延迟响应；刹停后继续缓慢移动|
|台阶|可部署准备/保持/恢复参考；有界的真实跨越进度和恢复误差|轮空转、碰墙抬身、前后往复刷进度|
|跳跃预载|COM参考位移/速度，支撑和可用行程|只蹲下不进入蹬伸|
|跳跃蹬伸|COM上升速度轨迹、有限窗口内释放能力，真实离地事件|不离地停在释放高度平台|
|腾空|可控的收腿、姿态/角速度；COM弹道用于测量和达成|把机体相对腿抬高冒充整机COM上升|
|落地/恢复|COM减速、目标平面速度、姿态/高度回收及持续稳定|接触一下或极小跳就领取完整成功奖|

反例验证分两层：先在同一组记录轨迹上比较逐项及完整折扣回报，再在需要时做一个奖励项的训练消融。正确跟踪必须比不响应、过冲、漂移等可实现反例具有合理回报优势。总reward、某一核“未饱和”或单项导数大均不能替代这项验证。

广域负成本还必须检查“主动提前摔倒/触发失败可省掉后续成本”的反例。在同请求/初态下按实际terminal cost、成功结束、失败、time-limit truncation和bootstrap语义比较折扣return；终止惩罚随新密度尺度定标，不盲用旧默认常数。不能靠关闭失败终止来解决这一问题。
