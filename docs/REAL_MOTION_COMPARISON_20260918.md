## 1. 视频中实际能看到什么

| 视频时间 | 可见运动 | 对训练提出的要求 |
|---|---|---|
| 0–18 s | 带斜面的多面台座上连续旋转，轮腿支撑位置随朝向变化 | 旋转×非平地、左右差动腿长、变接触法向，而非只在平面追yaw |
| 18–33 s | 离开/接近台座、行驶转向与地形衔接 | 保留历史、命令切换不断链，坡顶/坡脚和跨边界采样 |
| 34–37 s | 两轮跨越不同高度的边缘，腿部呈不对称姿态，随后继续行驶 | 一轮先上/先下、横坡、斜向入阶，双轮接触不是唯一允许状态 |
| 40–49 s | 连续高差通过和平台行驶，姿态/腿长随任务改变 | 进场—越障—落地—恢复整段训练，不只训练随机落在平台上 |
| 95.3–96.2 s | 压缩准备、伸展离地、空中位移、平台落地压缩并重新稳定 | 起跳请求锁存、接触阶段切换、落地吸能和反弹控制 |
| 107–114 s | 再次进出平台 | 在不同起始速度、落点和支撑条件下重复技能 |
| 117–136 s | 地毯/木板及坡台场地上的机动 | 材质、几何边界和动作组合，记录真实轮地滑移 |
| 138 s以后 | 比赛剪辑 | 说明存在实赛应用场景；画面不足以单独做底盘量化验收 |

95 s附近的细分时间是媒体时间，反映帧序列顺序，不作为起跳持续时间的实机标定。
视频也不足以证明无感知自主识别障碍；我们采用已确认的上层目标/起跳请求输入。

## 2. 我们已知的不足

### 2.1 停车时的慢滚与姿态偏置

在目标高度0.32 m、全零速度指令、回合开始2 s后且命令保持至少2 s的5075帧中：

| 指标 | 实测 |
|---|---:|
| 平移速率均值 | 0.04165 m/s |
| pitch均值 / 标准差 | −3.4767° / 0.0277° |
| roll均值 | +0.2844° |
| 高度MAE | 3.621 mm |
| 左/右轮实际dq均值 | +0.6970 / −0.6753 rad/s |

合计50.75仿真秒，跨多个回合，并非连续无reset站立50.75 s。
这里主要是稳态偏置＋持续慢滚，不能仅靠增加角速度惩罚解释或修复。
实际轮速与轮速目标也没有收敛到静止；两侧轴符号不同，不能因一正一负便认定平均速度为零。

优先候选：保留姿态基础项，增加有界、低速强化的小角度姿态核；零平移L1做−1→−2对照。
不同时叠加多阶轮加速度、强动作平滑和人为滚动阻尼。停车必须独立测60 s连续漂移、路程、
轮速和姿态均值；“不摇晃”不等于“不漂移”。回到原世界位置还需要上层位置反馈。

### 2.2 动作与地形尚未形成组合覆盖

旧Round4主要是平地速度、摩擦和推扰课程。V4无弹簧多场景原型虽能生成九类场地，
其地形路段命令主要为向前通过，不能据此声称学会视频中的台面旋转和异高支撑机动。

V5需明确采样矩阵：
- 平地：全速度域和停车。
- 坡面/台座顶部：站立、变高、低速转向、低到中速原地旋转。
- 台阶/边缘：正向、反向及斜向通过；一轮先接触、左右分别领先。
- 材质边界：上述动作的名义与低附着版本。
每格独立统计，而不是只统计“某地形占比”。

### 2.3 支撑高度与接触阶段

跨边缘时，基座下方几何高度不一定等于两轮实际支撑高度；以世界z或单个垂直采样点作为高度
可能在接触仍未转换时突然改变奖励。地面阶段应定义局部支撑面及估计来源，记录两轮各自支撑。
腾空阶段关闭地面高度保持和轮静止正则；落地后经去抖进入吸能/恢复，保持误差带才算成功。

### 2.4 气簧、主动轴和执行器边界

视频实机的质量分布、驱动、气簧和接触与旧七刚体研究模型不相同。
V5应使用19刚体、真实移动副与非线性被动力，并从四个根部主动输出轴控制四杆。
V5现有`RR_link2`质量疑点、研究惯量及端面重建行程基准需继续确认。
固定基座展示使用的重力/气簧前馈是检查夹具的伺服控制，不能当作RL已学会补偿或直接套进部署。
正式控制合同要固定是否采用前馈，训练、导出、回放和部署保持一致。

## 3. 对完整课程的具体补充

六阶段总预算仍为100000次更新，修改阶段内容与留出矩阵：

1. **基础10000**：停车偏置/慢滚作为独立验收；多高度静止、升降、加减速和变向，明确采样停车过渡。
2. **地形15000**：加入左右异高双轨、斜向跨边、正反纵坡与横坡；局部支撑高度和接触身份先通过验证。
3. **机动20000**：平地高速、台座顶面/低坡上的低中速旋转；新增平台边缘接近与刹停，按实际yaw验收。
4. **上阶20000**：学习预压缩—起跳—空中净空—平台落地；保存请求、失去接触、首次落地和恢复四个事件。
5. **下阶20000**：单轮先落、不同切向速度、弹簧压缩余量及反弹；不把所有落地强行限制为零pitch。
6. **混合15000**：模拟“台座旋转→离台→异高支撑→上/下阶→停车”的连续任务，不在技能边界reset。

姿态目标分阶段：停车强调小角度无偏置；加速/制动允许必要的可恢复俯仰；起跳/落地允许短时姿态变化，
随后收敛回目标。全阶段强压零pitch可能牺牲冲量、跨障净空或恢复能力。
轮腿差动不受左右动作相等的硬约束；可保留结构对称的数据增强，但左右接触不同必须能输出不同动作。

困难组合逐级放开：先一项难度，后两项组合，再连续路线。至少40%基础场景用于防止静止能力退化。
120 rpm、4 m/s、10°坡、50 mm上阶、100 mm落差仍为独立扩展评估，不能从视频直接认定我们应无条件可达。

## 4. 新增验收与记录

- 双轨异高：左右各领先、不同高度差/航向，报机体roll、两侧腿长/气簧压缩和各轮接触。
- 台座旋转：双向yaw、平台中心漂移、离边距离、每轮接触切换和力矩/功率饱和。
- 完整跳跃：请求到离地、空中、首次落地、恢复的事件序列；无有效离地不能计主动跳跃成功。
- 落地：统一物理步长下的法向冲量/峰力、弹簧压缩峰值、反弹和恢复时间。
- 连续路线：任务完成率、每种失败原因，以及路线后的60 s停车，不以timeout掩盖漂移。
- 所有条件固定seed集合，训练与留出场景分离；报告独立回合数与置信区间。

最终能力评估仍用机器人自己的遥测与物理任务定义。视频提供动作组织参考，不提供我们的验收数值。
