# V5 气簧安装与 Isaac 原生展示

2026-09-18补充：[工作域端点核算](V5_SPRING_WORKSPACE_REVIEW_20260918.md)发现，按当前CAD安装基准，
35°需压缩80.345 mm，略超80 mm硬行程；保留10%行程余量时膝内角应约48.67°以上。
因此名义姿态/动力步进通过不等于完整35–80°工作范围已通过，实机安装销距仍需确认。

## 安装方案

沿用 V5 CAD 的两端安装孔：**活塞杆上端接大腿，缸体下端接小腿**，跨过膝关节。
两端销轴随腿部运动转动，杆与缸体保持同轴伸缩。气簧推开两端，提供开腿方向的被动力矩；
瞬时作用力臂随膝角变化，因此不使用恒定膝力矩替代气簧。

当前树从下端构建：小腿→下端转轴→缸体→移动副→活塞杆，杆上端以球约束接回大腿。
这保留了原缸体端的 CAD 转轴和部件 frame，减少重定义；杆上端的闭合约束不属于关节树。
两侧对应名称如下：

| 角色 | 左侧 | 右侧 |
|---|---|---|
| 大腿 | `L_link1` | `R_link1` |
| 小腿 | `L_link2` | `R_link2` |
| 缸体及下接头 | `LLL_link2` | `RRR_link2` |
| 杆及上接头 | `LLL_link1` | `RRR_link1` |
| 下端转轴 | `LLL_joint2` | `RRR_joint2` |
| 伸缩移动副 | `L_spring_slide` | `R_spring_slide` |
| 上端闭合 | `L_spring_upper_mount` | `R_spring_upper_mount` |

## 华南虎实际实现的对照

核对对象为 `wheelbipe_V14_2.py` 实际选择的 `wheelbipeV14_2_1/wheelbipeV14_2.usd`，
以及 V14→V13→Wheelbipe25V3 的环境继承链。实际 USD 读回结果保存在交付包的参考证据中。

华南虎从上端构建树：`rear1`大腿→`spring1`杆端转轴→`spring2`缸体移动副，
再由 `*_s2r2_joint` 球约束将缸体接回 `rear2`小腿。
同样采用 **R＋P＋球闭合**，球约束设置 `physics:excludeFromArticulation=true`。
我们仅选择了相反的断环/树展开方向，实际仍是同一类两端铰接伸缩气簧。

不能只看其 URDF：本地参考 URDF 的移动副范围是−10至60 mm，而实际 USD 是−15至65 mm，跨度80 mm。
V14 当前配置启用 `mode='linear'`，400 N起始、70 mm内增至600 N、offset60.76 mm，
并有 reset 力随机项。实际 `_apply_spring()` 读移动副 q，计算压缩，再调用
`set_joint_effort_target` 施加轴向力。

`spring_settings['damping']=False` 仅关闭额外的伸缩分方向阻尼分支；资产本身的 spring actuator
仍设置 damping=50，且 reset event 会缩放阻尼，不能描述为“完全没有阻尼”。
我们的10 MPa曲线和安装尺寸来自自有模型，未照搬这些力/阻尼参数。

## V5 行程基准与推力

从清理后的 CAD 独立固体量得：缸体轴向长度125 mm、杆长80 mm；销孔中心到缸体网格近端
约16 mm，到杆网格近端约15.8026 mm。在目录205/125 mm标注端点与这些网格端点对应的
假设下，现有研究模型采用全伸销距 **236.8026 mm**。这不是实物行程标定，目录尺寸端点仍需图纸核对。

### 2026-09-19：接头尺寸重新核对

用户指出口述尺寸不一定准确，应结合机械图纸判断。因此237/157 mm仅作为
“205/125 mm本体加32 mm有效偏置”的**待核对假设**，撤回先前过早写入的“用户已确认”标记。
记录见`model/纯底盘_v5/gas_spring/installation_dimension_review_20260919.json`。

重新读取两侧源STL来源哈希、独立固体和销孔圆截面后发现：

| 量 | 上接头＋杆 | 下接头＋缸体 |
|---|---:|---:|
| 接头轴向外形包络 | −9～21 mm，长30 mm | −9～21 mm，长30 mm |
| 销孔轴线的局部X | 约0 mm | 约0 mm |
| 气簧固体近端的局部X | 15.8026 mm | 16.0000 mm |
| 接头与气簧固体的轴向投影重叠 | 5.1974 mm | 5.0000 mm |

因此要累加的是**销孔到相应安装基准的有效轴向距离**，不能相加两铝件的外形长度。
网格端点偏置之和为31.8026 mm，与32 mm假设相差0.1974 mm；左右一致。
下接头在缸体近端有对应平面三角形；上接头在杆近端没有对应的共面三角形。
进一步量测发现：上端孔底尖点在X=14 mm，半径3 mm的孔壁起点在X=15.8026 mm，
拟合圆锥夹角约118°。这对应**孔底钻尖的圆锥过渡**，不能直接认定为装配肩面或螺纹安装基准。
轴向投影重叠也不等于实体干涉判定。

现有材料是URDF/STL导出，不能直接读出原SolidWorks配合、螺纹旋入深度或内部止挡。
还需厂家长度标注端点和接头装配基准，或完整组件的全伸／全压销距测量，才能确定实机长度。
按旧研究基准，模型硬端膝内角35.669°；按237/157 mm假设则为36.045°。
这两个数都是条件计算，不是实机35°可达性的最终判定。

复现：`python tools/audit_v5_installation.py --output reports/v5_installation_review_new`。
输出包含来源校验、两侧量测、条件行程核算和实际网格投影图。

### 现有研究模型的运行基准

- CAD零位销距162.2728 mm，对应压缩74.5298 mm，位于末端保留区。
- 生成的名义姿态压缩56.89295 mm，在目录拟合0–72 mm范围内。
- 移动副 q 为相对 CAD 零位的伸长量：`s=0.0745297655-q`。
- 正的移动副 effort 使气簧伸长，物理引擎自动产生两部件间的内力及安装点反力。

10 MPa准静态推力为 `F=280+122.735918491u²+53.969804409u³ N`，`u=s/0.080`。
原生展示严格限制在拟合工作域；独立 MuJoCo 重力跌落验证将90–100%区间明确标为研究外推。
正常带气簧的4 s动力测试没有进入该外推区。动态阻尼/密封摩擦没有被这条静态曲线辨识。

## 原生 Isaac Sim 展示

训练仓库根目录，使用已安装 Isaac Sim6 / Isaac Lab3 的 Python：

```bash
OMNI_KIT_ACCEPT_EULA=YES python scripts/preview_v5_springs.py \
  --output reports/v5_spring_preview_new
```

窗口标题：`V5 FULL MECHANISM | PHYSX FIXED-BASE | 10 MPa SPRINGS`。
GUI保持打开直至手动关闭，输出目录必须是新目录。
解压独立模型包后，可在包目录执行 `python preview_v5_springs.py --bundle . --output ../v5_preview_new`。

- 蓝色：缸体；橙色：活塞杆；同色圆点：对应安装销。
- 黄色线/箭头：销轴、气簧轴向和等大反向推力方向。
- 默认整机双侧全景并自动往复，按钮可切换左侧特写；隐藏部件只影响视觉。
- 角度滑块及慢速往复改变六个主动轴的控制目标；从动杆和移动副由 PhysX 求解。
- 可开关气簧力、暂停、重置名义姿态、截取视口。
- 显示实际膝角、两侧压缩量、推力、安装销距和闭合残差。

展示使用**固定基座夹具**，便于看清连接，不是站立策略回放或承载节能评估。
悬空腿的气簧会将膝推向伸展端；为了可控往复，主动轴使用PD及离线虚功映射得到的
重力/气簧前馈。前馈只改变电机力矩，不写从动关节、不改刚体姿态。
正式导出模型仍为自由基座，固定夹具仅在预览stage中创建。

单独打开 `robot.usda` 会得到真实刚体与闭环约束，**非线性气簧力需要运行入口每个物理步施加**。
打包的预览脚本和MuJoCo验证脚本均包含该运行逻辑；USD不是能自动运行Python力模型的容器。
