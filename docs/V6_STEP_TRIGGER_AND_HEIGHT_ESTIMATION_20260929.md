## 2. 电机角度如何计算站高

每侧先将两个电机编码器按实测零位、符号与传动比映射到主动轴，再通过**完整闭链正运动学**求轮心在`base_link`中的位置`p_wheel_B`。相对膝内角不是膝电机角；不能把两主动轴作为串联髋膝直接套公式。共同转角控制摆腿，差动经闭链决定膝部形状。

设`g_B`为IMU姿态得到的单位向下重力方向。在轮子接触近似水平支撑面、有效轮半径为`r`时：

```text
height_if_grounded_i = r + dot(g_B, p_wheel_B_i)
```

这给出`base_link`原点到该侧支撑面的竖直距离，包含roll/pitch补偿；既不是欧氏腿长，也不是质心高度。双轮同平面可靠支撑时可融合左右结果。轮胎压缩、显著轮轴倾斜和坡面需使用实际接触几何/有效半径并计入不确定性，不能无限沿用固定半径近似。

RMCS已有可复用实现：`rmcs_rl/src/recovery_observer.cpp`第22–44行查`auxiliary−hip`闭链LUT并绕髋轴旋转，第140–147行计算上述高度。当前observer仅在恢复功能及标定配置就绪时实例化；不是普通RL已经上线的通用高度传感器。实施时提取/复用这段原生几何查询，供恢复和越阶共享，避免再造一套左右符号与LUT。保留独立的支撑有效性和时间戳；不要把恢复用的窄站高门槛复制到全0.23–0.43m越阶域。

必须区分以下输出：

|输出|可观测条件|使用范围|
|---|---|---|
|左右轮心相对位置、机构内膝角|有效编码器与已标定闭链|架空也可用；机械构型和激光安装几何|
|左右`height_if_grounded`|上述量加IMU姿态|接地假设下的候选站高|
|融合的站高与有效标志|已确认的支撑关系|抬升进度、支撑后的稳定判定|
|世界高度/相对原地面的高度|还需地面基准或外部估计|仅靠关节角不能得到|

架空或腾空时关节角不能确定真实离地高度；相同腿姿可整体被吊高任意距离。左右轮跨不同平台时不可无条件平均：保留每侧支撑面，按可信支撑侧使用；即使双轮均着地，简单均值也是相对两支撑面平均标高。壳体最低间隙另按壳体点计算。

## 3. 两种动作的输入与职责

|动作|策略命令|额外请求状态机|训练物理验收|
|---|---|---|---|
|普通单级、楼梯与普通双级上阶|持续前进速度、原站高/转向命令|无manual/laser STEP触发，无定时升高height_cmd|逐级轮子过缘、在对应顶面稳定支撑；允许合法底盘承托|
|原地/行进跳|原跳高命令与跳跃请求|已有跳跃请求/参考|真实释放、离地、顶点及落地恢复|
|单级/双级台阶跳|前进意图、预设本级落台高差与顶点|manual/laser同一跳跃入口|同次腾空越过前缘、指定顶面落台；每级独立计数|
|意外腾空、落地、自起|原部署恢复接口|恢复与R0流程各自负责|不能用课程通过代替真机接管验证|

### 普通上阶：速度驱动

低阶`rolling_up_03/06/10`、`rolling_stairs_3x04`保持普通路线模式，但明确关闭人工上阶相位；高阶`body_climb_15/20/25`及普通双级使用普通mode 0与前进速度。这里mode 0不代表零速度。没有触发距离、预设关节轨迹、收腿时刻或actor地形输入；持续推杆就是持续前进意图。

策略可以抬身、利用台面承托、收腿后继续前进；不要求一定发生底盘接触，也不要求腾空。`StepClimbTask`只做奖励和逐级验收：两轮依次过当前前缘、在当前顶面稳定支撑，才推进验收索引；不强制停车。直接越过第一级落在第二级不能获得两级信用。

普通上阶与主动跳跃分别验收：任一轮接触或合法底盘顶面承托均算有支撑；两者同时缺失连续达到80ms，锁存`flight_violation`，本回合不能通过普通上阶，也不再取得后续逐级信用。40ms接触抖动和短暂reset落地不会累计成跳跃；轮子悬空但底盘在合法台面承托仍允许。报告保留已完成平台的历史证据和最长无支撑时长，验收必须同时检查无该违规，不能只看累计平台数。

底盘接触只在已声明顶面内、真实接触点高度吻合且法向载荷向上时允许；Isaac接触patch逐个判断，非法侧壁/低地接触仍保留碰撞判定，不能整批屏蔽非轮接触。普通站高误差在前缘过渡区平滑放松，双轮上台后恢复；速度、姿态、力矩与真实机构约束仍在。轮缘误差使用非正广域项与精核，真实前進和有限建立承托获得进度分，不因停在台沿长期拿正分。

### 台阶跳：人工/单束请求

```text
前进接近 → 接受一次manual/laser跳跃请求 → 预载/蹬伸
        → IMU飞行证据 → 支撑估计恢复并保持 → 重新接近下一阶
```

- 控制器只消费预设课程、轮编码器里程、IMU和单束距离；`observe`接收的世界位姿与真实接触仅供奖励/验收，不能推进命令状态机。
- 持续前推不是每周期新请求。忙时不重启时钟；恢复完成后，第二次激光请求还需里程进展，持续同一近距回波不能立即计作第二阶。无回波不结束动作，也不解释为下阶。
- 手动训练入口是已知场地的预设操作者请求，以编码器里程表达接近事件；不能把仿真真值x偷换成实车已知位置。
- 新观测只使用原预留`frame[30]=jump_request*landing_delta_m*5`传递预设落台增高；网络35/81形状不变，距离、真值接触和世界位置不进入该槽，普通任务为零。
- 测距须有时间戳、有效标志和安装外参。水平束高于台阶顶面可能没有正面回波；倾斜束还需识别地面命中。一个距离点不能确定顶面标高或识别任意墙，故仅在已知场地使用预设高度。
- 可见性检查已发现：名义站高0.305m、传感器相对车体向前0.10m/向下0.20m时，水平束约高0.105m，不能探测3/6cm台阶正面。候选改用`sensor_pitch_rad=0.55`（约31.5°下倾），并以`ground_echo_margin_m=0.015`过滤近地回波：使用FK/IMU得到的左右假设支撑面，光束端点须分别高于两侧支撑面至少15mm；控制器消费投影前向距离，而不是把斜束量程直接当水平距离。**这些是拟定安装外参和工程阈值，尚非实车标定结果。** 不保证任意站高/姿态均可见；无有效回波不触发，人工请求仍可使用。
- 单束、FK/IMU和命令时间链的训练模型要与部署接口对应；噪声、掉点和延迟是工程先验，不能当作电机bag测得的传感器分布。双下仍由RMCS原生失能处理。

## 4. 候选课程与真实几何

|阶段|内容|PPO上限|
|---|---|---:|
|S1/S2/S3|原基础、完整移动、地形扰动与恢复|1000/2000/1000|
|S4|普通速度驱动上阶3/6/10/15/20/25cm、原3×4cm楼梯及下阶保留|1500|
|S5|原地与行进平地跳，原顶点bin与渐退助跳|1000|
|S5T|单级台阶跳3/6/10/15/20/25cm，manual/laser分别覆盖|600|
|S5D|双级普通上阶和双级台阶跳，分开采样及验收|400|
|S6|新旧动作、连续请求及组合扰动|1000|

原S5的2000拆为1000+600+400，总8500更新、20k环境、40.8亿转移上限不变。S5T的0.50跳跃池为平地0.15/单级0.35；S5D为平地0.05/单级跳0.15/双级跳0.15/普通双级0.15；S6原0.20池为0.10/0.06/0.02/0.02。其余复习份额保留，实际JSON见[技能合同修订](V6_STEP_CURRICULUM_20260929.md)。阶段能力通过双seed确认后才前进；预算上限不保证全部任务一次学会。

双级几何：第一级增高200mm、踏面800mm；第二级再增高250mm，顶面累计450mm。配置`rises_m=[.20,.25]`与`stair_heights_m=[.20,.45]`含义不同。第二级0.6m暂作为落点窗口，末面同高继续延伸；其长度仍待实物核对，不暗加末端下坎。800mm可用恢复距离还需扣除落点散布与车体扫掠。

每次跳的`apex`为从COM释放点到顶点的增高，不是台面高度；候选取本级增高加0.08m，即0.28/0.33m。参考保存起跳基准和本级落台高差，计算下降段到达落台高度的时刻，使用对应下降速度连续缓冲，最终COM位移等于本级增高。第二跳重置释放/顶点与请求起点，不能把累计450mm当一次起跳目标。真实提前触台可以进入落地奖励；广域项持续区分远误差，精核约束局部精度。

普通双级与双级跳都逐级确认，但成功定义不同。台阶跳需同次有效腾空、两轮前缘净空、指定顶面与落地区、支撑恢复；低地跳完再滚上不能通过，首级失败不能靠次级成功抵消。普通上阶不要求腾空，不能套跳跃事件数判定。专项未达标单列，不抹去此前基础能力已通过的事实。

## 5. 历史覆盖、实现状态与发布边界

历史旧`stairs_200_250`有两层问题：合同写的是累计顶面0.20/0.25m（第二级只增50mm），并且旧生成器未消费逐级字段，CPU实际生成3×4cm。旧下阶同样有几何缺陷。这些历史结果不得当作200+250mm能力。新合同已实现高度/踏面字段消费与CPU几何断言；Kaiser 20000环境场景已核对累计20/45cm顶面与80cm首踏面，真实机器人轨迹验收另行进行。
