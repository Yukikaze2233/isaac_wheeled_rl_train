# V5.1：基于固定评测的增量修复训练

本版本完成短测与续训验证；新的完整部署采用[V5.2奖励审计修订](V52_REPAIR_TRAINING.md)，
在本方案上增加0.15m宽核起步、分级晋级阈值与训练跌倒持续确认。

执行计划：`contracts/v5_scut35_repair_v51.json`。目标是修复低/高高度驻留、部分速度偏差和反向旋转掉高度，
保留已有actor能力、V5机械参数以及原固定评测标准。

## 1. 初始模型与预算

- 旧轮完成13334次6144环境更新，等效约20000参考更新后停在flat验收门，状态为`stage_gate_pending`。
- 初始actor选择固定评测排名最好的12486 checkpoint，而不是盲目选择最新文件。
- actor/critic输入仍为35D/81D，actor MLP仍为`[256,128,64]`；物理200Hz、policy50Hz、rollout24。
- 首阶段`flat_repair`预算6000参考更新，6144环境下为4000次实际更新。
- 后续landing/rough/spin_translate/high_speed/jump/mixed_robust继续沿用原预算。
- 全队列38000参考更新，6144环境下共25336次实际更新。预算不是收敛承诺。

奖励目标变化后采用actor-only迁移、新critic与新优化器。前50次实际更新只预热critic，期间固定学习率5e-5，
避免冻结actor产生近零KL而把自适应学习率抬到上限。之后恢复KL-adaptive PPO。
迁移时将动作分布std设下限0.08，恢复少量探索；actor均值网络权重保留。

## 2. 采样修复与不变的验收

原来的低/高高度保持只作为验收案例；新轮也把它们加入训练。
纯旋转及旋转平移按正反方向分别采样、分别诊断，避免正向好表现掩盖反向问题。
修复阶段旋转使用当前能力等级的固定指令；未过门的低速案例增加固定目标覆盖。

第一阶段相对采样权重：

| 组 | 相对权重 |
|---|---:|
| stand、动态height | 各3 |
| height_hold_low/high | 各5 |
| backward_05、forward_1、backward_1 | 各3 |
| 各反向旋转组 | 各4 |
| 其余已学技能 | 各1 |

后续阶段仍按50%新任务、50%前序任务分配，并将高度端点与方向副本放入对应分区。
最终鲁棒混合另保留5%材质切换。修复前后的27个flat固定案例逐项相同，门槛没有放宽。

## 3. 静止目标：速度与有限驻留

`rewards.py::StationaryAnchor`只对stand/height组的零速度、零yaw目标启用：

- 两轮支撑时锁定本回合位置锚点，短暂丢接触不会重新锚定以规避惩罚。
- 请求非静止任务或显式reset后解除锚点。
- 支撑外的相位关闭位置项，主动跳跃不受此项约束。
- 每秒奖励密度为`-(1-exp(-distance²/0.1²))`，范围[-1,0]。
- 这些静止组的平移L1速度惩罚由1倍提高到3倍；普通自旋保持原有系数。

位置真值仅用于reward，不加入actor。它促进有限时域少漂移，不宣称35D单帧策略具备绝对位置伺服。

## 4. 性能驱动的核宽、权重与转速

`performance_curriculum.py`按有符号技能组维护最近64个**真实完成episode**。
统计原始高度/vx/yaw绝对误差，不读取加权reward作为晋级依据；非轮触地、跌倒、出界等不计成功。
一个episode至少80%的帧为有效双轮支撑，才计为合格完成。

每次调整间隔至少200个4096环境参考更新。高度课程将权重与核宽成对变化：

| 等级 | 高度权重倍率 | 指数核1/e宽度 | 目标附近二次损失系数 |
|---|---:|---:|---:|
| 初期 | 2.0 | 0.050m | 1000 /m² |
| 中期 | 1.5 | 0.040m | 1087.5 /m² |
| 默认 | 1.0 | sqrt(0.001)m | 1100 /m² |

窗口高度MAE≤6mm且合格完成率≥98%时逐级回到默认；误差>15mm或完成率<90%时恢复初期等级。
权重和宽度在每个环境reset时锁存，不在同一episode中突然切换。

纯旋转上限按4→2π→8→4π rad/s逐级提高，最高不超过该组目标。
晋级要求高度MAE≤10mm、vx MAE≤0.1m/s、yaw误差达标且合格完成率≥98%。
明显失稳时可降一级。提高转速时恢复宽核/较高权重，重新巩固高度。
固定评测始终运行完整目标，不使用训练中的临时转速上限。

课程窗口、等级、最短保持时钟与计数随checkpoint保存。同合同resume恢复这些状态；
PhysX回合重启，未完成episode的累积量清零。课程只在修复阶段启用，后续阶段保留已学全速任务。

## 5. 奖励形状审计与来源边界

默认高度项是`exp(-clip(eh,±0.15)²/0.001) - (10eh)²`，`height_l1_weight=0`。
3cm处的高度奖励导数约-30.39 /m，不是梯度死区；平方项在远场仍提供随误差增大的代价。
这类导数是奖励对状态误差的形状分析，不是PPO直接对机器人施力，也不能单独证明收敛。

`analyze_chassis_rewards.py`调用实际`reward_terms`生成TensorBoard曲线：

```bash
python scripts/analyze_chassis_rewards.py --output reports/v51_reward_shapes_new
```

高度图横轴step为误差mm；速度图为误差mm/s；yaw图为误差mrad/s。典型默认密度损失：

- 高度误差1cm：约0.10516/s。
- 线速度跟踪误差0.05m/s：约0.005144/s，未包含静止附加项。
- 静止单轴速度0.05m/s：额外0.15/s。
- 驻留偏移5cm：约0.2212/s。

比较的是经过核函数、归一化、求和后的实际贡献，不是直接比较系数数字的倍数。
TensorBoard还记录每组`Curriculum/*`误差窗、完成episode数、核宽、权重和转速上限。

华南虎提供了相关progression组件，但当前公开V14及预训练配置关闭了该curriculum。
本实现借鉴思路，明确使用自己的统计口径和V5目标，不声称逐行复刻。
本轮无外部竖直助力，不复制160N；终止标准、关节/气簧限位和闭链门槛保持原定义。
动作平滑、力矩/功率、加速度及机械余量正则仍在；噪声与延迟继续由鲁棒阶段覆盖。

## 6. 运行可靠性

短测发现一次Kit启动期系统信息探测线程的`XOpenDisplay/getenv`原生崩溃，发生在创建环境之前。
训练与评测入口使用Kit文档提供的`skipDeferredStartup=true`串行化遥测启动任务，随后重新验证。
这项设置不改物理步长、求解器或训练算法。
远端仍由独立tmux管理；checkpoint封存、SHA校验、实际worker存活检查和TensorBoard继续使用既有流程。
