# V6 policy、课程与奖励源码审计及修订

日期：2026-10-02。用户要求参考华南虎和复旦、修复已证实问题、评估并接续训练。实际运行身份查`reports/v6_task_campaign_20261001/deploy/launch.json`，文档和本地配置不构成已部署证据。

## 1. 结论与修订范围

需要修复并续训；保留当前最新完整学习状态，而不是回到A或重新开一条未计费的线。网络35D/81D、20k环境、50Hz策略、200Hz仿真反馈PD、轮侧响应、求解器64/32和dense跟踪权重均保持。六条任务域各20k消费上限，历史1000不退款，总上限121000，离线评测不阻断连续PPO。

v4修复两类可验证缺口：持续低速与有符号平移×转向的联合覆盖；完成事件与持续正基线之间的回报排序。奖励事件单位显式冻结，失败扣分仍为单次200，不机械复制参考项目的数字。首次新合同做10次critic-only适应，之后连续actor+critic；全部计费，actor课程时钟只计actor更新。故障恢复不会重做已经完成的预热。源码、合同、独立角色预检及计划先提交、归档，再做一次封存迁移。

## 3. 覆盖审计及v4改动

v3的`sample_amplitude=True`实际乘数为0.4–1.0，因此命令1m/s的连续组只有0.4–1m/s，0.1–0.3只在坡道/启停途中短暂见到。平移和转向主要由固定轴向与`curve_low=[1,±0.6]`提供，缺独立有符号联合域。配置名“continuous_low”不能作为全低速已覆盖的证据。

v4对原有连续幅值组使用0.05–1.0；保留正/反向分组。原有curve组50%继续使用其固定命令，50%在原命令绝对幅值上限内独立均匀采vx/yaw，四种符号组合均可出现。所有样本仍走原命令slew与机械可达域投影；不是瞬时施加无约束目标。不会把楼梯行进命令随机成驻停或反向，地形专属组不改。

flat九固定高度各2%恒定配额已经在v3，不需要重新补；连续高度、0.23–0.43高度×运动交叉域、端点20%及边界加权均保留。静止共25%、升降15%、平移25%、启停20%、yaw15%不变。flat曲线联合子集占约3.125%（625/20k）；没有宣称每个连续格点都有固定访问次数。训练命令1–8s加20%长尾8–15s、真实停车延迟0–8s、完整停车周期及随机升降相位均已实现，继续保留。

固定评测命令、布局、用例、种子和判据全不改；exact-case采样不消耗新增随机数。旧合同仍沿用0.4–1.0原数值及原RNG顺序。新增LearningAudit命令均值、低速比例和四象限比例写远端TensorBoard，用于核查实际送给策略的命令覆盖，而不是只读配置。

## 4. 奖励单位与终止反例

v3原生密度总和乘policy_dt=.02一次；失败再减200，是单次事件扣分。SCUT的继承实现先生成`rew_termination`，再将全部reward项乘`step_dt`，配置-200在50Hz下实际为单次-4。数字同为200不能说强度相同。

但这不推出我方必须降为4：我方dense广域成本不饱和，Fudan又对单项dt成本限幅，两者的负回报域不同。用`calibrate_v6_rewards.py`原生跟踪项、gamma=.99、50Hz在广域大误差代数包络比较：10s继续回报约-90.845，带正确时间截断bootstrap约-91.446；首步失败成本4的回报约-4.914，比纠错/存活更高。200则约-200.914，故保留200通过该反例检查；100也通过，但本轮没有物理行为证据支持再调低它。

v4的`reward_units`分别钉死密度／真实失败／成功事件单位；native `episode_event_terms`与TB事件tag直接记录每次支付，不能再误乘dt。时间截断、出有限地块和边界截断不作为fall付费；机械失败仍优先于成功。该有限包络不是所有状态安全证明，尤其电机、异常姿态的无限成本需要继续观察真实样本优势和critic residual。

## 5. 完成前等待的回报排序

普通完美跟踪的正基线约5/s；gamma=.99、50Hz的继续价值上界10，而原成功事件仅5且成功终止不bootstrap。原生CPU反例：接近目标、命令0.3、站着不走的密度仍约4.068/s，立即完成约5.081，等待4s再完成约7.726；无需诉诸解析导数就出现错误排序。这是数学激励风险，尚未证明当前策略实际利用了它。flat没有目标完成事件，不能据此归因当前停车/旋转误差。

v4将成功事件设30，超过普通继续10；临近跳跃完成时base≤5/s、最大落地塑形≤7/s，保守按12/s无限继续为24，再加双级剩余一次性平台事件最多4，总28<30。平台事件仍由真实支持/顺序进度产生，不改变成功判据或以辅助成绩通过验收。新反例检查保证立即完成比受测等待轨迹高。请求序列、有限相位及困难地形仍需真实离线轨迹评估，不能把该局部上界当成全策略学习保证。

## 6. 现有奖励与policy不需要重复“修复”的部分

生效的是dense_tracking：广域pseudo-Huber成本加expm1精核，覆盖height/velocity/lateral/yaw/stationary。legacy precision字典的stationary_width=0.03当前不生效；改它不会修当前策略。yaw精核已经开启，权重0.35／尺度0.2rad/s。扩大精核或提高解析曲率不等于PPO得到有效优势；要看采样、回报排序与KL/优势。

旧落地正奖励漏洞已修：普通静站两项奖励为0，显式被动落地只用0.6s成本窗口；9/11mm反例已反转。fixed LR1e-4已接入，不把旧恢复adaptive飙升当当前问题。B权重翻倍失败只能否定那次干预，不能证明所有奖励都不是原因。

35D actor的IMU、编码器、命令及上一动作可以表达vx/yaw联合任务；目前没有证据需要改网络。其无历史隐状态估计，对持续延迟/执行器未辨识具有局部可观测风险；复旦历史/估计器是可参考机制，不在本轮授权网络不变的范围内。actor不读取真实地形/接触/速度；critic特权不应泄漏。恢复脚本/混合区间仍排除PPO，真实物理及控制前史保留。

## 7. 当前能力、性能和续训判断

v3实际只进入flat域：静站/升降、正反向低速、正反旋转、启停和曲线。该版本尚无固定全量评测，不能继承A曾33/45的成绩。之前A和S1终局已证明基础跟踪能力但有精度/方向/停车缺口；它们是不同封存模型。当前训练分项误差可以作为趋势，不是通过信用。

recovery、speed、terrain、jump、stepjump尚未进入本campaign，不能声称已经学会高速、自起、跳跃、普通两级200+250或跳两级。六域分别保存独立模型；实际多模型部署、切换与接管仍需实现/验收。未qualified腿bag仍未接入，轮侧响应与气簧模型保留。

200Hz原生探针20k、最大闭链1.485mm、闭链和气簧越界0，只验证工程入口；零动作fall3/非轮接触20336不是技能通过。v3早期17个去首轮真实TB更新中位12.828s，旧50轮45.143s，约3.52倍；优化器仅0.251s，主要仍是环境步进11.198s。单域20k按此估计约71小时、六域约18天加一次初始化/域，不保证后续复杂地形同速。SCUT4096环境最新flat公开event约1.955s/更新，但环境数、GPU/CPU绑定、求解器和资产不同，不能声称尚有固定多少倍“免费提速”。没有证据证明多线程竞争主导当前时长；监督重复32.9MB回执I/O已消除。

本轮需要继续学习，而不是仅替换配置就把旧模型当修好。v3在准备期间继续PPO；最终合法封存后以命名v3→v4回执和同root排他锁恢复最新状态，保留消费、学习谱系与task actor时钟。10次critic适应不增加actor时钟但计预算；首次critic actor不变、首次actor9个张量变化须实测。365 CPU测试与六域×五角色预检通过；运行后的真实回执另行记录，未verified前不声称部署完成或已修复行为。
