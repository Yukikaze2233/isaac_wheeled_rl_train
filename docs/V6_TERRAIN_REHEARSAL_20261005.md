# Terrain 常驻基础复习采样修订

日期：2026-10-05。版本：任务合同 v15。

## 改动与目的

当前 terrain v14 的训练采样仅含 20 个平地行为；原完整平地基础集有 41 个行为。v15 补齐缺失的 21 个行为，让九档静止、连续高度、双向低速、旋转、启停和请求序列继续被采样。新增 16 个双向高速平动组及 5 个地形高度组合，减少地形课程只在名义高度、单一速度下学习的覆盖缺口。

这是采样修订。原台阶几何、动作参数、奖励、物理、执行器、初态、域随机化和延迟配置保持冻结；新增组不代表已经学会。高速平动仅在平地练，未声称保留 speed 的全部 135 组或全部高速旋转能力。

总计 85 组、4096 环境；原 43 组的行为定义逐值保留。完整 41 个平地组实际占 1393 个环境。相比 v14，地形样本从 3118 降至 2291，约减少 26.5%；这是保留基础经验的成本，后续必须观察台阶学习效率与旧技能表现，不能仅凭配额宣称不遗忘。

新增高速组：前后向 2/3/4/5 m/s，各有名义高度和连续高度变体，共 16 组；全部绑定 flat。新增地形高度组：上坡、下坡、横坡、粗糙和材质过渡，vx 0.2–0.8 m/s、yaw ±0.1 rad/s、目标高度 0.26–0.36 m。目标高度采样的 `start_at_target_fraction=0.5` 控制命令起点，并不重写物理出生高度。

## 学习来源、时钟和预算

保留独立任务父树：terrain 的声明父仍为 flat。实际续训必须优先使用 terrain 已有完整封存检查点，不使用 speed 或 flat 权重覆盖已有 terrain 学习状态。首次无 terrain 检查点的父域初始化仍沿原原生规则。

同域迁移只接受两个精确来源：冻结 terrain v14，或真实已训练的 terrain v6。v6 路径先认证并组合原 v14 的质量修订，再应用本次采样修订；不能把声明过但尚未训练的 v14 合同当作真实检查点来源。

出生课程 origin 保留 1186。恢复 actor 时钟来自实际封存记录 U，不重置到 origin，不退还任何消费。speed 终点 5063、terrain 终点 2186、六域各 20000 消费上限与总 121000 上限保持不变；v15 不再次重开已结束的域。合同改变时原生 critic 适应按实际消费计账，不计 actor 更新。

自动切课以合同冻结的 actor 时钟为准，不以固定评测通过为前提；结束角色仍为 unassessed 研究候选。35D/81D、50 Hz 策略、200 Hz 仿真反馈 PD、160/2.5 腿 PD、轮侧响应保持；未 qualified 的腿 bag 不标为已接入。

## 固定评测与工程验证

四个 fixed 角色保持原 28 个 case 和原场景、行为目录、成员关系；新训练采样不进入评测定义。真实 `fixed_suite_contract` 投影恢复 SHA 绑定的 v14 元数据，独立期望表仍按 v14 固定角色继承，预检不放宽。

验证顺序：命名迁移和反例测试 → 干净提交归档 → 真实 30 角色预检 → 原生 4096 环境人口、地形绑定与控制语义探针 → 一次合法封存迁移 → 完整 actor/critic/Adam 恢复与首个 PPO 更新核验。探针只证明实现启用与配置一致，零 PPO、无能力通过或实车资格。
