## 统一修订范围

1. **通信作用位置。** 反馈链为物理传感器 → CAN/USB 返回 → PC PD 与策略共用的反馈；命令链为 PC 根据反馈计算力矩 → CAN/USB 下行 → 驱动缓存 → 实际力矩。50 Hz 策略目标保持和 200 Hz 仿真 PD 不变。额外策略整帧延迟关闭，不延迟内部目标来冒充已发送力矩的链路延迟。
2. **通信范围与丢包。** 按用户最新确认，工程先验覆盖亚毫秒到 15 ms，随机丢包和突发丢包均为零。单向预算记录完整链路，不给 USB、CAN、上位机排队各自叠加一份 15 ms，也不把策略 20 ms 周期算入链路。反馈和命令方向分别记录；合成 RTT 必须标明为两方向之和，不能冒充实测 RTT。旧 measured RTT 证据原字节保留。CAN 缓存等新报文是时序保持，不是丢包。
3. **原生缓冲与时间精度。** 使用现有 Isaac Lab 环形历史和现有 CAN 命令缓存；返回反馈需要覆盖超过一个 5 ms 物理步的历史。亚毫秒年龄不能用整数物理步直接舍为零；对非整步年龄的插值/力矩冲量近似必须记录，并验证角度跨周期、重置、时间顺序和长期时间精度。已有短 RTT 模型的限制不能靠删除检查绕过。
4. **旋转目标。** 普通原地旋转同时优化转速、车体姿态、双轮支撑几何与平面速度，不能为了转速牺牲高度、驻车或制动。左右轴按既有镜像符号和闭链几何转换；不直接要求原始轴角数值相等。新增几何或轮速共同分量的项之前，先核对已有 `no_fork` 与速度项的实际支付和覆盖，避免重复奖励。
5. **课程与复习。** 保留按 actor 学习时钟渐进加难、连续 PPO 和同一个 actor 串行接续。平地复习常驻静止、正反低速、正反旋转和指令归零后的制动；混采不能只保存一个总比例而遗漏高度×速度、方向×高度的联合曝光。难度速度和份额改动由固定容易/当前难度对照决定，不恢复 45 项阻断晋级、不因评测失败重复启停。
6. **动力学与接口。** 保持 4096 环境、35D actor/81D critic/6D 动作、50/200 Hz、PC 力矩控制、64/32 求解器、3 mm 闭链保护、1 s 稳定定义和已验证轮侧响应。腿侧 bag 未 qualified 的状态保留；参数与映射检查不能用其他机构的 PD 或力矩值替代。

## 能力矩阵与验证次序

| 能力/机制 | 固定输入与指标 | 验证目的 |
| --- | --- | --- |
| 通信零延迟、禁用与边界年龄 | 相同反馈、命令和 RNG；反馈年龄、发送/执行时间、丢包计数 | 零延迟恒等、0.04/1/5/10/15 ms 不被舍零或重复计算；随机/突发丢包均为零 |
| 静止与制动 | 230/305/430 mm；10 s 静止；正反 0.5/2 m/s 后归零；速度、yaw 角速度、高度、姿态、驻停时间 | 区分稳态、制动瞬态与探索；制动测试不依赖之前旋转存活 |
| 原地旋转 | 正反 1/2/3 rps，先低难度；双轮符号、共同轮缘分量、双轮位置、首接触部位、轴力矩、姿态 | 定位动作、几何、支撑和饱和的事件顺序；提前终止单独报告 |
| 旋转轨迹 | 世界坐标车体/双轮中点轨迹；足够多完整圈 | 分开偏心半径与圆心移动；平面速度不能直接命名为圆心漂移速度 |
| 恢复接管 | 固定倒地初姿与完整脚本；交接状态、稳定持续时间、后续指令 | 不把单个左侧出生当作泛化率，不把 12 s 未完成写成已跌倒 |
| 随机化与难度 | 同 checkpoint、同出生、同指令，分别关闭/启用新链路；容易/当前难度；均值/采样策略 | 分离通信、课程、探索因素；不同时改奖励权重来破坏归因 |
| 性能 | rollout、优化器、日志、启动/评测墙钟分别计时；同样本数量 | 验证整更新耗时，不将 writer 局部提速或只读解析时间当成 PPO 提速 |

先完成通信实现和 CPU 时序验证，再做同一检查点的原生物理对照；之后才冻结最终权重、份额与难度时间表。行为对照优先复用现有 native FSM、控制和模型，不增加第二套机构求解器。
