## 1. 证据与尚未解决的归因

当前 v8 源码为 `5de8fb814c4b157c52858a4f38b8bad5788c4860`。完整 actor 1951–2050 与 2051–2150 的恢复结束回合分别为 8227、7987，生产者成功计数均为 0；最新窗口 5526 超时、2461 失败。hold 最新点轮速通过约 21.3%、机体角速度 37.5%、腿速 36.4%，最长稳定段均值约 14 ms。它们是探索训练读数及帧/人口统计，不代替同条件确定性验收。

不可变消费 16000、task actor 1960 的轮侧标准差为 0.663/0.654，初始 task actor 390 为 0.348/0.325；轮速目标的探索幅度接近翻倍。按真实 scale=10 与轮半径 0.06 m，当前轮速目标 1σ 对应约 0.40 m/s。目标噪声并非实际轮速噪声，不能用理论独立概率代替物理回放。

当前脚本/BLEND 排除与终止责任实现正常：原生 PPO 只消费完整 actor interval，actor 造成的末步失败仍收费。有效恢复/平地样本约 60.7%/39.3%，并非名义 65%/35%；两群有效 advantage 统一标准化。actor 与 critic 是分离 MLP，原生 RSL 分别裁剪两者梯度；不能把 critic loss 较大直接解释成 actor 梯度被挤掉。

### 混采的作用与本轮预算口径

参考 SCUT 的在线混采，旧技能持续获得当前策略生成的样本，可以降低“完全不再访问旧域”造成的遗忘风险，不能提供不遗忘保证。同一个 actor 仍同时接受新旧任务的 PPO 更新；采样份额、有效样本、回报/advantage 尺度、旧行为实际访问范围、探索和随机化分布都会影响保持程度。当前 v8 已常驻完整 flat 41 组，名义 35%、本次有效约 39.3%，clean 均值仍回归，就是“混采存在”与“能力保持”必须独立验证的实例。不能再写“SCUT 常驻全域，所以不会退化”。

用户指定首轮 **speed 3563 更新、terrain 1186 更新**用于本轮调度安排，不是所有机器人/任务通用的资格门，不表示跑到该轮数自动学会，也不取代独立行为验收。它们的消费与 actor 时钟、来源及自动 endpoint 由冻结 v9 调度合同单独定义，本文不改账本或额度。speed 指平地高速域，不等于 SCUT `rough_dash` 的粗糙地形、冲刺及其他联合任务已经全部覆盖；terrain 承担它自身命名的地形任务。恢复重设计另行冻结后再训练，不随本次 speed 切换热启用。

## 2. 基础奖励统一，接稳目标由可见命令定义

保留原全局基础 reward：所有环境使用相同 dense velocity/yaw/height/stationary 核、姿态项、物理/接触/执行器成本。**不再按 recovery 身份删除五个正峰常数**，不在隐藏相位中切换基础奖励。这不是新增正等待奖励；不新增按时间、holding 占用、ready/stable 门通过数量或相位持续时间付费的项。

接稳需要的轮/腿速度与 roll/pitch 角速度成本采用零中心广域项＋精核，并由 actor 可见命令的 `quiet` 连续混合启用。普通零速 stand 与恢复零速 hold 用同一目标、同一尺度与权重；非零 yaw 命令下继续跟踪所需 yaw，不惩罚其目标旋转。腿速度目标只在固定高度、无 jump 请求、无显式升降任务时为零；若 35D 无法辨认升降过程，不能硬加隐藏 h-dot/无条件腿速目标，须先缩小该项生效范围或不加入。已有同类成本应合并定标，避免重复收税。

保留当前真实失败事件一次 −200、完整成功事件一次 +30 作为待定标起点，不把它们直接视为最优权重。事件仅依据原真实 outcome，不为“启动 BLEND”“hold 门某帧全过”“最长稳定段增加”另发奖金。阶段训练可只采 stand follow-up，但成功仍须真实 1 s hold＋原 stand follow-up；其成绩不冒充前进/转向或整套非常规姿态自起通过。

门的真实要求保持：反馈有效、支撑与底盘离地、姿态/角速度/高度、轮腿速度、连续稳定 1 s，以及独立真值 hold/平台保留证据。若负成本与成功事件的回报排序不对，修改 reward 定标，不放宽验收。

## 3. 从真实脚本交接状态开始的三层课程

当前静态 profile 库强制初始 root/joint velocity=0，只能表示几何出生姿态。新课程必须使用 V6 原生脚本动态回放生成的交接 fixture；不能把完美直立静止姿态冠名“脚本末态”。所有采样仍仅在正常 episode reset 写状态，无回合中传送。

| 层级 | 主要出生状态与训练范围 | 保留与推进 |
|---|---|---|
| L1：纯接管接稳 | 同资产 V6 脚本完成 BLEND 后的真实状态；近直立与中等余速均有样本。先用平地/平台上 stand follow-up，练 actor 接管后的稳定与完整 stand 成功 | 完整 flat 41 组常驻；按冻结 actor 时钟渐入难度。课程样本与原始非常规整链验证分别统计 |
| L2：交接边缘与命令释放 | 出生时间向 BLEND 前/中扩展，回放实际 200 ms 混合；余速、倾角、非对称腿姿和延迟历史覆盖真实分位区间。逐步加入稳定释放后的正反平移与 yaw | 保留 L1 及 flat 配额；hold 失败、释放后跟踪失败、平台/下一级立面碰撞分开统计，不把台阶通过混为接管能力 |
| L3：完整恢复链 | 从原非常规 profile 启动 V6 释放/翻正/混合脚本，包含原 hard、台阶与双级平台；接稳后执行原 follow-up | 全链样本逐步增加，L1/L2/flat 保底常驻；脚本失败由脚本工程修复，不能期待 PPO 从被排除的样本中学会翻身 |

比例/时钟关键帧须在交接 fixture 与 delay/std 分离探针完成之后冻结；现 clean 均值退步证据不足以直接选定比例。采用单调、reset-only 全局 actor 时钟插值；同合同恢复不重置原点。到预定时钟推进训练采样，不重复销毁 worker 或引入 45 项阻断门；固定回放持续提供质量证据，自动结束仍保留未通过清单。

动态 fixture 至少包含：全部主动/被动关节 q/dq、root pose/twist、气簧状态与闭链约束、真实平台/位置、施加载荷与物理随机化身份、FSM/observer 与已完成混合标记、上一实际动作/目标/PD反馈、观测/动作延迟 ring 历史与时间戳。不能只恢复 q 再把 dq、twist、缓存清零。fixture 的资产/FSM/物理 dt/执行器合同/延迟版本逐 SHA 绑定，不能将 V5 轨迹或 1 kHz 旧成绩当成当前 V6 200 Hz 资格。

fixture 对延迟历史无法精确导入时，先在同场景重新播放原脚本前缀到所选交接时刻，再把控制权交出；这一前缀仍不进入 PPO。闭链碰撞/接触求解缓存无法序列化的部分需要原生短回放验证连续性，禁止用重置冲击制造容易状态。动态随机化不应独立重采到与已录状态矛盾的质量/质心/气簧参数；扩域由同参数轨迹重新生成或带条件匹配的 fixture 实现。

## 4. 探索管理必须在原生分布端完成

保持动作语义与 likelihood 一致。不要在环境中把 sampled action 乘一个小系数来“降探索”，也不要改轮速 scale 或 torque cap 掩盖策略噪声。环境安全饱和仍沿原合同；PPO 使用实际采样的原始动作与原生 log-prob。

最小方案优先从分布端限制可训练 std 的研究上界，或按全局 actor 时钟给明确 exploration 日程。上界/日程值由 matched replay 中的实际门连续段、失败率和运动保留共同选取；不同腿/轮 action 有不同尺度，不能六轴盲用同一数字。父 std 只作为对照点，未证明最优。

若用参数投影/有界参数化，采样、旧 log-prob、新 log-prob、KL 与 entropy 必须来自同一个有效 Gaussian std；不得只改采样或只改日志。投影发生在完整 PPO update 边界，checkpoint 保存实际 std 与日程时钟；完整恢复校验 Adam 参数身份及状态。若改 distribution 参数化，必须显式迁移而不能声称 Adam exact。先不同时更改 LR、entropy、奖励权重和 replay 配额，保留归因能力。

## 5. 冻结前的最小探针与反例

先做同初态、同随机数、同原判据的有限回放，不展开全量 2 GB events 扫描：

1. 已完成父 flat 与 recovery 16000 的 deterministic、delay-off quick 对照，冻结其均值退步结论与原始 SHA。下一探针补同 checkpoint 的 delay-on，以及封存模型/真实动态交接 fixture 的独立回放；分别统计脚本到交接、hold gate 连续段、真正 motion release 与释放后跟踪。
2. 同最新 actor 均值比较 deterministic/current-std/parent-std；延迟与随机数匹配。目标是区分均值遗忘和探索噪声，不把 deterministic 回放通过当训练随机策略资格。
3. 动态 fixture reset 与原脚本连续到同一交接时刻的配对回放，比较状态/观测/PD/延迟年龄及短时行为；覆盖平地、200 mm、双级首层/末层平台。出现初始冲击或平台身份不符先修 fixture。
4. 对同一冻结 rollout 按有效 recovery/flat 样本分别记录 raw reward、GAE return、advantage 和 critic residual 的均值/尺度，再检查统一标准化后的贡献。不要仅凭全局 value loss 或 nominal 65/35 判断任务竞争。

reward 排序测试使用当前 `policy_dt=.02`、`gamma=.99`，连续成本只乘一次 dt，事件只付一次，真实终止不 bootstrap；同时检查密度与完整 discounted return：

| 反例对照 | 必须满足的方向 |
|---|---|
| 同观测/同零命令/同物理轨迹，只换 recovery/ordinary 身份 | 基础与可见 quiet settling reward 相同，不能只差一个隐藏常数 |
| 高度 9/11 mm、同样其他误差，或轮速 0.20/0.30 m/s | 改善误差不能降低回报；跨真实稳定门不能出现奖励台阶或饱和后“更坏同价” |
| 姿态、角速度与轮腿余速逐级减少 | 广域成本在精核以外继续区分改善；不能用解析导数声称 PPO 必然学会 |
| 达稳并完成合法 follow-up vs 长时间留在未释放 hold | 在冻结可达轨迹和事件回报下，合法成功完整 return 更好；等待不能靠额外进度奖金获利 |
| 1 s 连续稳定 vs 多段短暂过门但反复中断 | 真实 outcome 前者通过、后者不通过；不为累计门通过帧支付可套利事件 |
| 提前释放/失去原平台/撞立面后失败 vs 留台完成 | 前者不能靠末步 mask、正 tracking 峰或 terminal bootstrap 得更好回报 |
| 普通非零 yaw/高度变化 vs 强迫所有速度归零 | 合法命令跟踪应胜出，quiet settling 成本不能劝策略欠速或拒绝升降 |
| 脚本与 BLEND 轨迹 vs actor 末步失败 | 前者不进 PPO；后者保留真实成本、失败事件与正确 GAE 边界 |

一个只用于单位与排序的算例：若理想基础峰为 5 reward/s，则每策略帧基线 0.1；100 帧后合法成功且第 100 帧一次 +30，按 gamma=.99 的 return 约 17.43；等待 1000 帧且无成功约 10.00。前者能够承受的额外 discounted 成本约 7.43，超过它时排序可能反转。这不是实际轨迹得分或最优奖金证明，说明必须把可达轨迹的真实成本代入检查，不能孤立凭“+30/−200 很大”宣布激励足够。

反例使用物理可达轨迹与相同命令，逐项保存 reward 分解。若成功排序失败，先冻结一个最小定标修订再短训练验证；不重复烧长分支、不借 gate 放宽掩盖问题。本稿不授予任何模型/fixture 动态资格，也不改变已经消费的更新账本。
