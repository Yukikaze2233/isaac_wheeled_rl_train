# 环境机制详解

逐项说明 flat/rough 环境里每个机制的语义、实现位置与调参入口。所有数值默认值见
`src/wheeled_tasks/direct/wheeled_biped/env_cfg.py`。

## 1. 观测合同(35D policy / 43D critic)

| 段 | 索引 | 缩放 | 说明 |
|---|---|---|---|
| 指令 | 0–2 | ×1.0 | vx, vy(恒0), yaw_rate |
| 高度指令 | 3 | ×5.0 | 状态机飞行偏置叠加后编码 |
| 角速度 | 4–6 | ×0.5 | 机体系陀螺仪 |
| 投影重力 | 7–9 | ×1.0 | 姿态的等价表示 |
| 腿关节位置 | 10–13 | ×1.0 | 相对默认站姿 |
| 轮位置槽 | 14–15 | — | 恒 0(mute_wheel_pos_obs) |
| 腿/轮速度 | 16–21 | ×0.1 | |
| 上一帧动作 | 22–27 | ×1.0 | |
| 模式标志 | 28–34 | — | normal/stair/slope/recover/jump/height_target/state_time |

全观测 clamp ±100,nan/inf 置 0。**修改任何一维必须同步部署 CONTRACT.md。**

Critic 额外获得(非对称,不参与部署):真实线速度(3)、真实高度(1)、
DR 参数回读(4:增益缩放/腿摩擦/轮摩擦/质量缩放,采样值由 events 函数返回,非估计)。

## 2. 动作管线(6D)

```text
policy action (50 Hz)
  ├─ 腿 a[0:4]: target = default_pos + 0.5 × a        (位置目标)
  ├─ 轮 a[4:6]: target = clamp(10 × a, ±30)            (速度目标)
  ├─ 动作扰动: target × scale + bias + N(0, std)       (dr_action_noise,默认关闭)
  ├─ 动作延迟: act_delay ring (1–3 步 = 20–60 ms)
  └─ 每 4 个物理步(200 Hz)重复下发
```

气弹簧不占动作维:每物理步按 `F = 400 + (600−400)/0.07 × 压缩量 + rand(±50N)`
主动施力于 prismatic joint。

## 3. 延迟与噪声

- **观测延迟**:IMU(角速度+重力)、关节位置、关节速度三路独立 DelayBuffer,
  每 env 在 reset 时从 [1,4] 步重采样(20–80 ms)。
- **动作延迟**:解码后统一过一路 [1,3] 步。
- **观测噪声**:均匀噪声逐流注入(陀螺 ±0.25 / 重力 ±0.05 / 关节位置 ±0.025 /
  腿速 ±0.5 / 轮速 ±1.0)。
- DelayBuffer 为预分配 ring(写指针推进,无每步分配)。
  延迟不可每步重采样:帧间差分会被策略利用,reset 时重采样即可。

## 4. 域随机化

| 时机 | 项 | 范围 |
|---|---|---|
| startup(一次) | base 质量 ×0.9–1.3、腿质量 ×0.9–1.1、base COM ±4/2/2 cm、轮材质摩擦 0.5–1.2 | |
| reset(720 步门控) | PD 增益 ×0.75–1.25、腿主动关节摩擦 +0.05–0.2、轮摩擦 +0.05–0.25 | |
| reset | root 姿态 roll/pitch ±0.15 rad、动作扰动参数、弹簧力偏移 ±50 N | |

**720 步门控**:摩擦/增益的 PhysX 写入每 720 控制步最多一次(`_dr_gate_steps`),
避免 reset 风暴下的写放大;特权回读随写入同步刷新,保证 critic 拿到的是真实采样值。

## 5. 指令课程(特殊模式桶)

`manager/mdp/commands.py`:非站立 env 按比例分桶,桶互斥、每次指令重采样重掷:

| 模式 | 占比 | vx | yaw_rate | 起始迭代 |
|---|---:|---|---|---:|
| spin_low | 15% | ±0.1 | ±(2π–3.25π) | 3000 |
| spin_mid | 15% | ±0.1 | ±(3.25π–4.5π) | 4000 |
| dash | 30% | ±(2–3) | ±2π | 2000 |

基线指令 vx ±1.5、yaw ±π;10% 站立 env 指令置零;一半非站立 env 用 heading 模式。
迭代门控构成隐式课程——行为按训练进度分批出现。

## 6. 状态机与跳跃奖励

- **腾空判定**:轮载消失(接触力 < 1N)且基高 > 0.30 m → in_air。
- **7D flags**:in_air 时 jump/height_target 置位,state_time 为窗口内归一化时间。
- **飞行高度偏置**:in_air 时高度指令 +0.02 m(收腿轨迹入口)。
- **落地奖励**:窗口内 track_height(σ=0.025)+ 垂直速度收敛(σ=0.25)。
- **跳跃全轨迹族**(`mdp/jump_rewards.py`):二次参考轨迹 h(0)=h0, h(T)=hf, h'(T)=0,
  四项稠密奖励 = 轨迹高度跟踪 + 垂直速度跟踪 + 腾空轮零力矩 + 触地前轮速预旋。
  原则:**奖励整条轨迹,绝不只奖励顶点**;辅助辅助力必须与 reward 权重课程配对使用,
  否则策略会学到"减小动作等辅助力衰减"的反向梯度。

## 7. Rough 地形

`make_rm_rough_terrain_cfg()`:8m patch × 6×6 网格,flat 20% / 台阶 20% /
反向台阶 20% / 坡面 20% / 反向坡 20%(步高 0.125 m,坡角 0.15 rad)。
`terrain_flags_from_types` 把每 env 所在 patch 名映射为 stair/slope 布尔喂给状态机
(7D flags 的 bit1/bit2),向量化实现,无逐 env 循环。

## 8. 课程

`RewardWeightProgression`:按 track_height 窗口均值(64 步,device 上累加,
窗口满才同步一次)是否连续达标 + 最少 episode 数推进阶段;终段再达标恢复默认权重。
`BaseVerticalAssistForceProgression`:阶段化衰减基座向上辅助力,与权重阶段绑定。

## 9. 终止条件

投影重力 z > −0.5(倾覆)‖ 基高 < 0.1 m(跌落)‖ base 接触力超限 ‖ 时长 20 s(截断)。
粗地形下出边界按截断处理(不吃终止惩罚)。
