## v2 验证缺陷及 v3 修复：实际回放完整50/100/200 ms

审计时 `WindowReplay.window()` 的缓存 key 只有 `segment` 与 `start`，没有 `count`。验证循环对同一起点依次请求 50、100、200 样本，第二、第三次命中第一次 50 样本缓存。v2 两侧报告中名为 100/200 ms 的记录 `samples` 仍为 50，且同一起点三个结果完全相同。

这不影响各段完整闭环回放和固定 2000 样本的拟合窗口，但意味着 **v2 只能提供 50 ms 的输入回放证据**。后续 v3 已将缓存身份改为 `(segment, start, count)` 并完成重跑。两侧各120条记录，全部输入回放记录满足 `samples == horizon_ms`；v3 完整闭环结果与 v2 数值完全相同。整理后的验证入口增加了实际样本数检查，不符直接拒绝写成该 horizon 的有效结果。

两个主动轴一起驱动、保留真实闭链是正确的；问题是当前拟合窗口几乎只有共同转动、伸缩激励很弱。对 18 个拟合窗口分别去均值后：

| 共模角标准差 | 0.26872 rad | 0.26839 rad |
| 角差标准差 | 0.00761 rad | 0.00530 rad |

| 角差参考跨度 | 0.15998 rad | 0.15998 rad |
| 实测角差跨度 | 0.04959 rad | 0.04578 rad |

相同窗口发送力矩峰值左 25.17/23.75 N·m、右 25.41/24.12 N·m；它们不覆盖完整电机峰值能力或整个膝工作域。大腿共同旋转覆盖较广，不等于相对膝伸缩、起跳负载或着地冲击也覆盖广。

拟合的数值 Jacobian 在局部是满秩的，奇异值范围左约 3.68–38.63、右约 2.42–35.82；因此不能仅凭相关性断言优化问题数学上不可辨识。但在固定零位、气簧、惯量、刚性支架、单位力矩增益、105°止挡假设下得到的八参数最优点，不等于这些参数分别是独立的物理真值。不同参数可能补偿未建模负载和接触误差。

时间常数左约 0.835/3.532 ms、右约 1.073/2.822 ms。1 ms 采样下可以拟合离散一阶系数，但不能把它们直接解释成 USB 时延或电机本体唯一时间常数；主机发送时标、CAN交付、反馈时间、惯量与摩擦模型误差都可能进入这个等效值。特别是低速负载与止挡邻域，库仑摩擦、黏滞阻尼和 armature 都会影响跟踪相位。

## 力矩输入和 force-balance 诊断的含义

`identify_pair_dynamics.Replay.real_torque` 来自 `tau_frame_api` 经坐标符号变换，遇到系统/使能帧则保持上一次有限力矩。这是**主机提交的 MIT 力矩 payload 假设**，不是板端确认交付、更不是独立测得的轴端力矩。当前 `response_1khz.npz` 中有 `tau_frame_api`、`tau_cmd_api`、`tau_preclip_model`，没有独立输出力矩真值列。

`torque_input` 是把这一 host command 输入候选动态系统；它适合检验“提交命令→机械运动”的组合模型，但不能独立校准实际力矩比例。代码固定 `gain=1`，这是避免尺度自由度吞噬误差的明确假设，不是已证实的电机扭矩标定。

`diagnose_pair_response.py` 的 inverse/force-balance 结果只用于诊断：

1. 速度、加速度由量化角度经 Savitzky–Golay 微分得到，受平滑窗口和编码器量化影响。
2. `heldout` 分组又调用了一次 `lsq_linear` 在 heldout 自己拟合；其 residual 不能解读为在 heldout 上验证 fit 参数。
3. 左侧 fit residual 仍有 −3.31/+2.07 N·m 的均值，heldout 自拟合后约 −2.73/+1.05 N·m。静态/方向性偏差不能靠增加 armature 或 lag 解释，可能含负载、零位、摩擦不对称、力矩参考或支架姿态的混淆。
4. 当前 joint parameters 是带机械结构和假设的等效模型，不是拆机辨识得到的 motor-only 常数。

## 最低可接受准入范围

目前可接受的是明确标注的**条件研究候选**：固定车体、悬空、保留真实重力与气簧，PD160/2.5，1 kHz反馈力矩/50 Hz目标，近伸展的实测姿态与已验证幅频范围。用于复现相同任务、比较候选和分析失败是合理的；不应宣称覆盖完整腿域、地面负载、跳跃/台阶、自起接管、温升或堵转。

在把腿参数直接用于当前完整课程前，仍需要分别解释观测到的自由运动与仿真止挡区间，而不是只看闭环均值；解释或界定负载/零位残差，并处理v3真实100/200 ms和旧PI宽域回放暴露出的漂移。窗口身份与完整horizon重跑、左右Isaac同轨迹对照已经完成；它们没有消除上述全域适用性问题。保留腿侧名义模型，并把候选仅放入明确标记的有界研究对照，而非悄悄升级为全域中心值。

**轮侧可以先迁移。** 六轴合同可让四腿维持原名义参数，仅两轮采用经单独验证的惯量/摩擦/响应参数；PD、减速比和力矩上限保持不变。证据必须逐轴标明 `wheel adopted / leg candidate-not-adopted`，不能用一个全局 `plant_fit_applied=true` 让人误以为六轴全部已通过。轮侧也要先完成其 Isaac 回放和响应模型预检，再用同checkpoint旧/新双种子评测及预算不清零的复习机制接续。
