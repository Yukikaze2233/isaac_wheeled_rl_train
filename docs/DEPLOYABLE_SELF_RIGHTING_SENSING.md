# 用可部署观测量实现倒地自起：观测、控制与仿真验收

状态：已实现可选 Isaac Sim 传感器闭环模式并完成 50 组对照；**尚未接入 RMCS 或实车**。
约束：**不增加硬件传感器**。恢复路由、阶段切换和 RL 接管只依赖现有六轴编码器、BMI088 和遥控器的观测，PhysX 真值仅供传感器仿真与离线评分。原控制器的真值门禁不能照搬。

## 1. 先限定可以看见什么

使用四台 DM 与两台轮电机的编码器角度／速度、BMI088 的原始加速度／角速度及其姿态估计，以及 DR16 开关。控制器知道自己发出的轮力矩，可在安全幅度内主动探测；**不把驱动反馈力矩当成轮地法向载荷**。BMI088 加速度已进入姿态滤波器，但 RMCS 尚未将其作为带时间戳的独立观测发布。

这些量已在冻结机械模型的仿真中实现分姿态闭环动作和**经验性、有失败退出的自动接管**，但不能在所有情形区分「轮子承重」与「车壳着地／被外力托住」，也不能排除低摩擦地面上的匀速滑动。故不能声称从仅有这些信号重建了牛顿制轮载或保证任意地面、任意外力下必然站稳。可信度不足时允许持续捕获或退出，不以未知值冒充成功。

所有动作版本同时声明被验证的地面摩擦、质量、姿态和扰动范围；超出该能力范围或观测异常，不能静默降级为普通 ONNX 平衡。

## 2. 同步快照和闭链几何

每个 200 Hz 周期先形成带 `stamp, valid, age, confidence` 的不可变快照；1 kHz 驱动层独立检查 DR16、故障和反馈超时。四根主动轴先在真实驱动反馈端依据**确认过的反馈周期／饱和规则**管理连续圈数，再变换到模型输出端；不能把 MIT 的 `P_MAX` 当作回绕周期，也不能把设零姿态的 110° 内膝角当作辅助根轴的角度。

仿真入口 `MotorEncoderAlignment` 按四轴 **1:1 独立传动**处理模型轴与电机读数：`q_model = q_at_encoder_zero + sign*e`，在合成电机反馈端解缠后再映射，未对同侧髋／膝加入差动项。当前仿真特意选用冻结模型 `balanced_standing_pose(110°)` 的四维模型角 `[0.866817,-0.561652,-0.866817,0.561643] rad` 和**合成的**四个 `sign=+1` 作往返测试；这**不是实车四台 DM 的已标定 L2 偏置或方向**。实车虽然在 110° 机械姿态读数已设为四个零，但仅知道内膝角不能唯一确定四个主动杆的模型角；还必须确认大腿绝对姿态、闭链分支以及每轴符号／反馈端。仿真不向电机发送设零命令。对应流程见 [V5_ZERO_TRANSMISSION_ALIGNMENT_20260926.md](V5_ZERO_TRANSMISSION_ALIGNMENT_20260926.md)。

在冻结仿真装配分支中，可用左右各自的闭链 FK／单调 LUT 从 `delta=q_aux-q_hip` 估计内膝角、气簧压缩、轮心在 base 坐标中的位置及壳体最低点；越出 LUT、闭链分支不明或校核残差超界时拒绝动作。附件的 45 点映射**仅验证了仿真机械**，不能直接作为实机标定。

设 `g_B=R_WB^T[0,0,-1]`，`p_wheel,B` 为轮心相对 base 的 FK，轮半径为 `r`。平地上**已确认该轮接地时**，该轮给出的条件性 base 高度为：

```text
h_base|wheel_contact = r + g_B · p_wheel,B
```

两轮接触假设成立时比较两侧条件高度，拒绝超出地形／标定误差的分歧；单轮接触假设只给出对应一侧的条件高度，并提高不确定度；没有可信接触时高度设为**无效**，不是填 0.305 m。左右轮相对世界高低 `-g_B·(p_L,B-p_R,B)` 无须绝对高度，可用于侧翻时锁存上下侧。壳体与平地的几何间隙也只能作为**有条件的排除证据**，不能单独证明轮承重。

世界轮角速度由机身 gyro、连续关节角速度和模型运动学求出；不能在新仿真控制器中直接读取 PhysX 轮刚体速度。轮速里程计只在接触假设成立、IMU 加速度与轮运动一致时作为低置信度平面速度；垂向速度只在该假设成立时对条件性 FK 高度差分。匀速侧滑或外部托举依然不可判定，所以这些速度都必须带 `valid`，且保留适用地面限制。

## 3. 通过主动探测估计支撑，而非虚构接触力

每侧返回 `CONTACT_CANDIDATE / NO_CONTACT / UNKNOWN`，并附时间戳、置信度和原因；不输出一个假的 `Fz`。候选判据组合如下：

1. IMU 姿态、角速度和**原始加速度**识别触地冲击、侧躺→矢状面转换和沉降。冲击只能说明外部发生了作用，不能辨别是轮子还是车壳，也不能把加速度计的瞬时值直接解释为接触力。碰撞／大角速度期间拒绝不可靠的姿态修正。
2. 编码器＋闭链 FK 给出相对轮高、机械余量、**假设轮着地时**的高度和壳体间隙。只有特定装配分支和已实测的几何误差范围内才使用这些判据。
3. 临近正立、角速度已降低且机械余量安全后，对左右轮分别施加短时、对称、限幅的小力矩探测。仿真候选为每轮正／反向各 15 ms、幅值 `0.18 Nm`，比较**已发送力矩、轮编码器角加速度和机身 gyro 角加速度**的相位／响应；双轮的两种方向均验证后停止探测，给姿态留静置窗口。幅值、响应阈值和力矩限幅属于**冻结仿真配置**，实机必须重标定。若轮空转、单轮接触、响应不一致或探测期间姿态失稳，标为 `UNKNOWN`。
4. 要求双轮接触候选、姿态与几何一致、六轴速度降低，且 IMU 加速度在着地冲击后恢复可预期的静置响应，并保持独立的迟滞和驻留时间。轮被障碍物卡死也可能像「高阻抗接地」，所以主动探测**不是接触力传感器的数学替代品**；未知时拒绝接管。

恢复阶段需要接触的切换使用这个估计器的**相位相关置信度**：`ORBIT→THRUST` 可依据冲击／姿态推进和轮阻抗的较早证据，要求低力矩和有界动作；进入 `BLEND` 则要求双轮均完成稳定探测、更严格的几何和运动一致性。不能把仿真的 `3 N/5 N` PhysX 接触力条件直接照搬为编码器阈值。

建议的经验接管候选：

- 倾角 `<8°`、机身角速度 `<0.75 rad/s`；
- 在双轮接触假设下，几何高度 `0.27–0.36 m`，壳体间隙和闭链余量均为正且包含标定误差；
- 双轮探测完成且阻抗／IMU 响应一致，编码器／轮里程计没有明显空转或动态残留；
- 上述条件及观测有效性保持一段待仿真和台架标定的驻留时间；原真值门禁的 100 ms **不是**不装传感器时已经验证的安全驻留时间。

当前只能提出上述候选，不应先把探测脉冲幅度、惯量比、打滑阈值或驻留时间宣称为已标定值。尤其不能通过无限延长姿态驻留来解决恒速滑动、壳体托地等不可观测情形。不能确认时维持有界捕获并超时退出，而不是无限扫腿或自动进入 RL。

## 4. 自起状态机和触发

双下时驱动失能、重置恢复时钟和历史；确认此前处于双下后，再达到**双中**且 DR16／关节／IMU 新鲜时发出一次性请求。任一拨杆离开双中、失联、反馈丢失、机构越界或恢复超时均取消并锁存，必须重新双下→双中才能重试。物理释放试验的 0.2／1 秒零力矩窗口不能自动用于每次真机触发。

1. 用 `g_B` 及有效的支撑／高度状态锁存路径：近正立走站立准备，中倾角走收腿-放支点，前后倒走有方向的收腿-回转-蹬伸-捕获，侧躺走上侧伸长／下侧摆动后重新判前后方向。高度未知时不可假定已站立。
2. 轨迹参考从当下**连续**实测角开始；普通目标同侧两根轴共享圈数，定向回转不包角成最短路。控制器始终在模型输出端算有界腿、轮力矩，四 DM 采用 PC 侧纯力矩模式；参考角不会同时下发给 DM 内部位置 PD。
3. 收腿看真实跟踪误差与闭链余量；回转到蹬伸以相位相关的接触置信度和实际姿态／进展为条件，支撑不确定则减速、限制行程并有界退出；侧翻选腿只在几何区分可靠时锁存，不每帧反复换边。
4. 捕获时依据连续 pitch、gyro 和剩余可用力矩估计制动距离，尽早减速，避免把一次穿过正立误判为站稳。该能量制动改进目前只是设计，必须与原脚本在同一物理条件下闭环比较；不得声称已改善原试验中的 60–73° 反向摆动。
5. 接管前固定 ONNX 命令为零速、0.305 m，单独维护脚本和策略目标，影子推理；传感器限定的门禁通过后，沿用 200 ms **模型侧力矩混合**，之后才进入正常 RL。低位落地但仍接近正立时先走收腿／放支点路径；若在 PREPARE 中稳定倒扣，可在当前 8 秒预算内最多重新选路一次，不能无限扫腿。稳态确认后再渐进接收遥控运动指令。

未来 RMCS 接入时，`RlController` 应是六轴力矩唯一拥有者；恢复位于其 `PREPARE` 内，保位测试组件不参与这个执行器图。当前已完成的是 Python Isaac Sim 200 Hz 恢复／50 Hz 推理验证，**并未完成 RMCS 的 1 kHz 硬失能联调**。各阈值必须随恢复配置版本和硬件标定记录。

## 5. 已完成的离线观测核查（不是新闭环成绩）

使用 `reports/v5_activation_capture_20260925/` 中**原本由 PhysX 真值门禁控制**的 50 个、12 秒案例和 50 Hz 轨迹，真值仅用于事后给样本贴标签：

- 在 PREPARE/CAPTURE 仅要求倾角 `<8°` 与角速度 `<0.75 rad/s`，得到 706 帧候选，其中 92 帧不满足「双轮垂向载荷均 `>5 N` 且非轮接触 `<5 N`」。有 **5 个案例**连续至少 5 帧（采样间隔 20 ms）出现这种误判；全部属于低蹲卸力后的壳体承重阶段。单看 IMU 不足以判接管。
- 用四主动轴＋IMU 和冻结模型的 45 点闭链表计算条件高度：在两轮承重、壳体无明显接触、近正立的 22,736 个样本中，仿真内部 FK 相对根高度的绝对误差中位数／95 分位约为 0.1 mm；在 506 个不满足该支撑标签的样本中，95 分位约 0.153 m，最大约 0.246 m。这个对比说明**支撑是 FK 高度有效性的前提**，不是实机已达到亚毫米精度的证明。
- 在相同原轨迹中额外用条件性 FK 高度 `0.27–0.36 m` 回放筛选，五组低蹲卸力的连续 IMU 误判窗口均被排除；仍有 27 帧未承重候选，但没有连续五帧的未承重窗口。这**不能证明轮部探测或新控制器的闭环有效**：轨迹由真值门禁控制，50 Hz 降采样可能遗漏更短的危险窗口，FK 高度也需要先确认接触假设。
- 现有 50 组原控制器的末尾严格成功 `44/50`、曾达到稳定 RL `48/50`；这些结果**不是本设计的成功率**。

离线轨迹不能提供新控制器作用于物理系统后的成功率，因此已进一步完成第 7 节的**仅 IMU＋编码器**闭环试验。

## 6. Isaac Sim 新闭环试验的验收方法

在同一冻结资产和 12486 ONNX 上，控制器接收模拟**现有硬件**的编码器角度／速度、IMU 加速度／gyro／姿态，以及自己下发的力矩和遥控指令。PhysX 接触力、根高度／速度、被动膝真值及轮刚体世界速度不参与恢复阶段或 RL 接管判据；仿真生成加速度报文时可读取物理状态，事后评分器可读取上述真值。当前噪声实验添加编码器位置 `0.0004 rad`、速度 `0.022 rad/s` 量化，以及 gyro 单次 `0.01 rad/s`、静态偏置 `0.005 rad/s`、重力方向分量 `0.003` 和加速度 `0.15 m/s²` 的高斯扰动；并**未复现真实 BMI088 EKF、USB 延迟／丢包或实体 DM 反馈端语义**。

按现有 10 姿态×5 次、12 秒的矩阵与原控制器逐案对照；另外改变质量／气簧、摩擦、轻微斜坡和初始角速度，并覆盖单轮承重、车壳承重、轮子空转、滑动、编码器／IMU 卡常值或漏帧、DM 反馈过圈。分别记录路线、相位、误判接管、拒绝率、最终严格通过、最大机械余量损失和翻正后反摆。原条件下争取不低于 `44/50` 严格通过、测试集合内误判接管为零；不允许靠把所有案例都拒绝来满足误判指标，还需报告逐类覆盖和拒绝原因。这是**限定工况的经验目标**，不是仅凭现有传感器可以实现的普遍安全保证。

实机第一步是校核真实传动／闭链与 IMU；在估计器经过仿真、台架和受控实机试验前，保持当前 `calibration_ready`、`soft_limits_ready`、`imu_alignment_ready` 的门禁，而不是填入仿真数值绕过它们。

## 7. 已完成的 Isaac Sim 闭环对照（2026-09-26）

所有试验使用相同模型 manifest `dbec8e586cf29d9540db7040b133b3ff1170c1c700ff05eda64d94d8561c3dec`、12486 ONNX、10 姿态×5 次和 12 秒窗口；仿真器逐个校验模型依赖文件。无需新增硬件传感器，仿真代码仅增加 `scripts/inspect_v5_activation.py --sensor-only` 的可选路径，估计器位于 `src/wheeled_tasks/chassis/recovery_observer.py`。`--sensor-noise` 在传感器路径上叠加上述可复现扰动；不传选项时原真值实验的既有 `values`／`diagnostics` 轨迹与保存快照**逐元素相同**。

| 指标 | 原真值门禁 | 编码器＋IMU | 编码器＋IMU、有扰动 |
|---|---:|---:|---:|
| 末尾严格通过 | 44/50 | **45/50** | **45/50** |
| 曾达到稳定 RL | 48/50 | 49/50 | 48/50 |
| 正立／低蹲／两类释放，末尾通过 | 19/20 | 18/20 | 18/20 |
| 左右侧翻，末尾通过 | 10/10 | 9/10 | 10/10 |
| 前后 45°，末尾通过 | 7/10 | 10/10 | 8/10 |
| 前后倒扣，末尾通过 | 8/10 | 8/10 | 9/10 |

有扰动的 5 个末尾未通过案例中，低蹲卸力 replica 1 与前倒 replica 2 未进入 RL，分别在等待落地／准备阶段耗尽预算；另 3 个曾进入并稳定过 RL，但未保持到观察窗口最后 1 秒。`reached_stable_rl` 与末尾 `success` 不能合并计数。

正式记录位于：

- `reports/v5_activation_truth_recheck_20260926/report.json`：同代码的真值控制对照；与历史 `reports/v5_activation_capture_20260925/traces_000.npz` 的轨迹逐元素相等。
- `reports/v5_sensor_only_recovery_final_20260926/report.json`：无附加观测扰动的传感器闭环。
- `reports/v5_sensor_only_recovery_noisy_final_20260926/report.json`：上述量化和 IMU 扰动。每个目录均含脚本快照、NPZ 轨迹和 TensorBoard；传感器试验的 NPZ 另有 `sensor` 数组。

在 50 Hz 记录中，无扰动试验的 1,384 个、小扰动试验的 1,442 个 `probe_confirmed` 帧，事后对照均未发现“两轮垂向载荷至少一侧 `<=5 N` 或非轮接触 `>=5 N`”的帧；BLEND 采样帧也未见同类情况。**这只是已测试材料和 50 Hz 离线采样的结果**，不能证明 200 Hz 每个瞬间都无误判，更不能由一次量化／噪声设置推出实车能在滑动、夹持或不同载荷下可靠识别接触。仿真自碰撞仍关闭，质量／摩擦配置仍单一；当前结果不构成实车自起使能许可。
