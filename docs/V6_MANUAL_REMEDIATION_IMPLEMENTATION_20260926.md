# V6动态参考补救课程：实施与接续

用户已授权由助手确定计划并接续当前训练。主合同：`contracts/v6_manual_remediation_v1.json`。
本轮从V5.9最新完整actor接续，运行身份和实际启动状态由单独部署回执记录。

## 1. 已实现的训练边界

- Actor：36D → 256/128/64 ELU → 6D；策略50Hz，物理／PC反馈200Hz。
- Critic：114D，新增实际质量倍率、COM偏移、落点位移、COM速度／上升量／请求后位移及真实接触phase等特权信息。
- 显式迁移35D首层，新增／启用的29、30、31、35列初始化为0；继承actor其余权重和探索参数，重建critic／optimizer。
- 资产使用`model/纯底盘_v5_232mm/urdf/`，manifest SHA保持
  `dbec8e586cf29d9540db7040b133b3ff1170c1c700ff05eda64d94d8561c3dec`。
- 四腿模型侧40Nm及原轮力矩包络、膝40–110°、气簧80mm行程；前膝／后髋、外部链传动1:1。

同为36D的后续阶段仍校验动作、控制周期、机械身份和观测布局。不同合同只做actor迁移；相同合同才恢复optimizer。

## 2. 动态参考及reward

`references.py::CommandReference`不读取地形、接触或仿真状态，只消费命令与时钟。

- 平移：普通命令采用原有有界斜率；专项`velocity_curve`采用平滑启停／反向轨迹。
  实际送入actor的参考速度差分形成`a_x_ref`，同时用于动态俯仰目标`atan(a_x_ref/g)`。
- 速度：精跟踪核＋宽核＋Huber项；pitch指数和平方项使用同一参考，额外记录原地旋转的平移代价。
- 人工STEP：按意图与命令时钟升高／降低／恢复；上阶目标0.40m，下阶目标0.28m。
  训练随机化按键时间、保持时长和出生接近距离。没有前向raycast分类或仿真真值触发。
- JUMP：统一跟踪**相对接受请求时的整机COM位移与速度**；预载、推蹬、弹道、缓冲参考连贯。
  最终高度目标是COM相对真实离地点的上升量，0.03／0.06／0.10m分别评估。
- 推蹬结束仍未离地时，不继续领取释放高度平台奖励；记录释放速度不足。
  腾空强调收腿／姿态；落地奖励按已达到的COM目标比例加权，避免极小跳跃解锁完整恢复奖励。
- 释放位置／速度在200Hz物理子步观察并锁存首个有效支撑丢失样本，随后由debounced FLIGHT确认；未确认的接触反弹被丢弃。

Actor第30项在STEP中是基座高度命令增量，在JUMP中是COM参考位移；第31项是对应参考速度。
第35项为纵向参考加速度。模式语义、坐标定义和合同必须随模型一起交付。
`reference.height`在jump中仅是`raw_height + COM_reference_displacement`的内部表示，不能当作实测基座高度目标。

上限7000次更新，1,622,016,000 transitions；通过阶段门槛并满足最少训练量后可提前交接。

第一段配额：恒速正反平移30%、启停／反向过程30%、站立20%、合格慢转回归15%、其他既有任务5%。
新的专项不使用生存率前沿限制其目标幅值；完整任务域仍在相应阶段和复习池中采样。
跳跃专项60%环境用于跳跃，联合阶段保留25%跳跃、25%目标台阶，避免复习份额被大量组名稀释。

## 4. 阶段推进与能力统计

- 每段先用输入actor建立固定基线，包括35D→36D迁移后的基线。
- 保护固定54项clean／USB名义案例里父模型已通过的项目；同时要求本段`promotion_case_names`全部通过。
- 通过主seed后再用确认seed验证。两次连续评测出现保留项回归时停队，保留段初和候选模型。
- 未达门槛但耗尽预算时，保存checkpoint并停止后续阶段；不把预算完成改写为能力通过。
- 最后联合阶段要求全套固定案例通过，每个seed每条件20回合。
- 阶段接受只声明该段目标与保留能力，输出回执包含具体能力case列表。

TensorBoard记录`/reference/*`、`/reward/jump_*`、`/sampling/*`、`/domain/*`。
分组指标包含各参考phase的高度／速度误差，以及请求、进入TAKEOFF、有效腾空、正COM释放和成功的逐回合计数。
评测trace保留参考与实际phase、COM位移／速度、动作、轴速度和轮目标，便于后续定位失败环节。

## 5. 本地验证与已知边界

- 35D→36D普通模式一致性、探索参数保留、阶段预算、硬门槛与旧合同回归测试。
- 在隔离的待提交源码树中运行163项相关测试，全部通过，包含机械资产hash／闭链及部署数学回归。
- 实际PhysX验证：台阶真实尺寸、参考输入一致性、部分reset不污染其他环境原始高度。
  坡道出生移到平坦接近区，已检查小规模首200ms有效性；完整坡道能力尚未作为本轮目标发布。
- 64环境真实PPO：4次更新后从封存快照恢复，再完成2次更新，actor更新与ONNX导出通过。
  `reports/v6_reference_probe_final_20260926/`。
- 35D父模型和恢复后的36D模型均已进入真实固定评测链路；短训不是技能通过证明。
- 无外力、无reset后位姿／速度写入的执行器参考探针：
  10cm COM目标实测上升约9.60cm、释放速度约1.397m/s、有效腾空约0.28s并稳定结束。
  另外两档也发生有效腾空，但完整落地条件未全部通过。
  `reports/v6_reference_takeoff_com_20260926/probe.json`。

参考控制器只用于动态可达性验证，不替代PPO动作，也未把其成绩标成RL策略能力。
本版使用显式参考与稠密reward接续原actor；未添加外力、root速度注入或未经验证的示范数据。
