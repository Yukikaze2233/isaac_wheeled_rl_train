执行计划：`contracts/v5_full_range_v54.json`。

## 1. 为什么整合重训

V5.2完成4000次实际更新后仅4/27案例通过；V5.3虽在64环境60次短测中保住18项并达到19/27，
但6144环境250次更新时降至6/27。V5.3已于316次更新正常停止并封存，未把短测结果当作长期修复成功。

本轮从头训练一个35D actor／81D critic的统一策略，旧模型和完整回收产物保留作对照。
基础完整域统一建立后，再做接触恢复、主动跳跃、复杂地形和鲁棒组合，避免继续堆叠窄域微调。

SCUT V14基类确有`default_height_cmd=0.22`、`height_range=[0.20,0.42]`；派生配置也存在覆盖。
借鉴的是全域训练和稠密过程设计，不把另一台机器的0.42m上限直接套到V5。

## 3. 高度域的几何与力矩依据

模型规格SHA-256：`9f6e71b1b79d1b346c0d06c57682c13cb1d40a59c1639240933e47dc21f0b53b`。
双轮接地、近水平且质心投影位于轮支撑线的条件几何边界约0.20520–0.35695m。
指令取0.21–0.35m，位于该边界内；对应膝内角约36.98–77.73°。

15个高度点的闭链／虚功核算显示，静态腿轴力矩幅值最高约5.28N·m，
考虑60N·m/rad位置PD静差后的策略动作幅值最高约1.84，低于现有限幅3。
这是模型内准静态必要条件验证，不是自由平衡策略、冲击承载或实机尺寸标定。
低位使用现模型已有的72–80mm气簧压缩研究外推段，未更改力曲线或行程。

```bash
python tools/analyze_v5_spring_limits.py --height-targets \
  0.21 0.22 0.23 0.24 0.25 0.26 0.27 0.28 0.29 0.30 0.31 0.32 0.33 0.34 0.35 \
  --output reports/v54_height_workspace_new.json
```

### 合法目标与软余量代价保持一致

原统一余量项在0.21m合法姿态处的风险值约0.913，会持续惩罚低位驻留。
新版将几何参考存入`contracts/v5_height_workspace_v1.json`，运行时核对模型哈希和膝余量参数。
设实际风险为r，目标高度对应参考风险为r_ref，则软代价使用：

`max(0, (r - r_ref) / (1 - r_ref))²`。

目标姿态不因其不可避免的构型被额外惩罚，进一步逼近止挡仍受罚；到硬边界r=1时归一化代价仍为1。
机械越界判定独立执行。原始风险也记录到`/mechanics/working_margin_raw_max`，避免只看到调整后的reward。

## 4. 稠密参考与首次覆盖

升降采用三次平滑过渡，端点竖直速度为零；上下全行程过渡6秒，端点驻留2秒，
最大参考速度约0.035m/s。完整往返案例为38秒，端点驻留案例为18秒，后者前6秒用于过渡。
训练随机化轨迹相位，让首批样本就包含低位、高位和过渡；固定评测从确定相位开始。

移动／旋转高度采样覆盖两端及连续区间。部分episode直接使用抽到的目标高度指令，
其余使用6秒高度过渡；这只改变指令，不在仿真中途写入机器人姿态。
速度／yaw指令保留物理意义的slew，目标域本身没有按训练轮次逐步解锁的窄域上限。

高度保留原窄核和平方误差，再加入宽核伴随项`0.5*(exp(-(e/0.08)²)-1)`，
增强远场信号，同时保留近目标精度。升降中竖直速度跟踪参考速度，而非统一要求竖直速度为零。
落地增加高度／竖直速度恢复目标和冲击项；跳跃继续使用相位参考轨迹，未引入外部竖直辅助力。
同时修复推扰采样：每技能`push_m_s`真实控制训练推扰幅度，不再被阶段默认0覆盖。

| 阶段 | 4096环境参考更新上限 | 6144环境实际更新上限 | 固定案例数 |

| terrain_full_range | 5000 | 3334 | 72 |

200Hz物理、50Hz策略、rollout24；整轮上限7天。基础阶段固定LR=1e-4、actor和critic共同从头训练；
后续从已验收actor迁移，重建critic／优化器，固定LR=3e-5，先进行50次critic预热。
后续阶段50%新任务、50%前序任务排练；每250次实际更新固定评测，首次第10次及每100次更新封存恢复快照。

阶段必须达到其完整固定目标才能晋级；预算不足时结束并报告未通过，不无限重试。
新姿态／地形目标扩展不放宽原有案例的精度或漂移阈值。
每个高度轨迹还检查竖直速度误差并报告实际高度最小／最大值，不能用“存活”代替完成升降。
