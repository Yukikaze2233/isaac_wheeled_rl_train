# V6 精跟踪与有界恢复课程

日期：2026-09-27。正式计划：`contracts/v6_scut35_precision_v1.json`。

## 数据依据

200Hz作业`v5-scut35-20260927T012444Z-3b863f`在累计300次更新后结束，
状态为`regression_hold_best_preserved`。第200、300次的双seed评测均丢失
`backward_05`、`rotate_1`、`rotate_1rps`和其扰动版本的通过状态。
第200次这四项先因高度超限失败；第300次倒退速度也退化。

- 基线倒退0.5m/s的速度MAE为0.0967m/s，第200次为0.0654，第300次为0.2568。
- 第300次前进/倒退0.5m/s实际约±0.243m/s；±1m/s实际约±0.475m/s。
- `rotate_1`高度MAE从4.19mm增至17.46mm，固定验收上限为10mm。
- 恢复后初10次到结束前10次，训练高度误差从4.54mm增至17.85mm；
  每策略步`no_fork`平均代价由−0.01284降至−0.000917，侧倾相关项也改善。

这证明有能力回退，并与目标竞争相符；不能仅凭均值认定纯粹灾难性遗忘。
原速度宽核、主核和SmoothL1每步均生效；直立时0.257m/s误差仍可获得约
89.7%的最大速度项回报。需要补充精度分辨率，而非继续扩大核宽度。

## 奖励设计

在原宽核与大误差SmoothL1之外，增加有界负精度项：
`weight * expm1(-(error / width)^2)`。所有项按实际策略周期乘`policy_dt`。

| 项 | 权重 | 宽度 | 生效范围 |
|---|---:|---:|---|
| 前后速度精度 | 1.0 | 0.15m/s | 普通移动/旋转，排除静止、人工台阶和跳跃 |
| 横向侧滑精度 | 0.25 | 0.1m/s | 同上；约束机体侧滑，不宣称提供世界位置反馈 |
| 静止平面速度精度 | 0.5 | 0.03m/s | 零平动/零转动命令且有支撑 |
| 支撑高度精度 | 1.0 | 0.01m | 非跳跃的支撑期，台阶使用已有动态高度参考 |

负误差项不乘直立门，避免姿态改变隐去误差。
原`no_fork`在5cm处的单位跳变改为超过5cm后、2cm宽度的连续饱和代价；
原`no_fork_square`仍保留。关节/气簧/闭链硬约束保持独立。
跳跃的蓄力、蹬伸、收腿、落地继续使用已有分相位目标，新增站立高度项不压制腾空。

## 每一段课程的防回退

- P0增加高度复习以及±4rad/s、±1转/s旋转配额；平动、起停、静止继续混采。
- 每段入口将累计保护用例映射到训练行为族。扰动版本共享行为族；域随机化仍按阶段合同执行。
- 对保护行为族设置合计25%的均分下限；从各组高于保留下限的富余份额中调配。
- 调整份额时保留`stand`、`height_rehearsal`、`speed_retention`、`stand_retention`池的既有下限。
  因此特殊技能课程的高速≥20%、静止≥15%不会因保护配额而被挤掉。
- 全量评测发现的、早于计划引入但已经通过的技能可作为复习组加入，不能丢弃其保护。
- 段内新通过项经双seed确认后加入保护与恢复点；下一段据更新后的保护集重新分配下限。
- 评测用例、门限、seed、机械/通信条件保持原200Hz固定协议。只有通过阶段门才晋级。

## 回滚、学习状态和预算

使用第100次保留checkpoint恢复actor、critic、Adam及探索参数；逐张量核验后，
用10次计入预算的critic-only更新适应改变的回报。它们是本轮新优化工作，不冒充旧预热。

旧作业已经花费300次更新。新运行显式传入`--consumed-updates 300`：

- 预算计数从300继续；恢复权重的学习谱系从100继续，分别记录。
- 原P0上限500，剩200；总上限7000，剩6700。已经回滚的200次不返还预算。
- 每50次检查P0；其他阶段按各自块大小检查。
- 每个worker在训练前保存当前合同下的完整学习状态，供首个块退化时回退。
- 连续两次回归可回到最后通过累计保护的完整状态，学习率每次乘0.5；每段最多2次。
- 所有重试消耗原阶段和全局预算，不自动追加更新、不绕过验收。
- 重试或预算耗尽时明确结束；最终进度写`phase=finished`和真实状态，避免残留“正在评测”。

35D/81D、200Hz物理、50Hz策略、16384环境以及1ms USB下行模型继续使用。
本轮调整属于奖励与采样修复，不包含新的电机辨识参数或机械映射标定。
