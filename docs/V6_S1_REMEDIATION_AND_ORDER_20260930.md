实际静止误差成本（每秒密度，支撑且零命令时）为：

```text
-1.5 * (sqrt(1 + (e / 0.10)^2) - 1)
+0.75 * expm1(-(e / 0.04)^2)
```

广域项没有裁剪。约 2.5cm/s 的小偏置在 10s 可积累约 25cm 位移；最新305/350mm静站正属于这一量级，而不是超过6cm/s后的窄核远端问题。速度成本与累计位移是不同量，不能用“漂0.1m和1.05m”直接推断瞬时速度奖励相同。即便针对旧 Gaussian，6cm/s 处也不是数学上精确零导数。误差成本有区分度仍不保证 PPO 优势或参数梯度有用。

## 4. 高速课放到恢复之后、台阶跳跃之前

用户建议合理，但“恢复”须拆成平地低速前置能力和高速/地形中的复合能力。当前顺序是S1→S2高速→S3地形扰动/自起→S4台阶；高速本来就在台阶/跳跃前。本次实际调整是把**平地扰动和非常规姿态接管前移到高速之前**，同时在高速后继续保留高速受扰复习。

|顺序/预算身份|内容|优化上限|

S2不能在nominal高速池中彻底删除刚学会的恢复。候选池为：运动45%、启停/过渡20%、静站15%、高度10%、平地恢复10%；正反向和正反转配对，不把旋转全当自旋平移。前置学到的随机化继续在复习lane保留，高速主任务从名义到联合扰动推进。

高速目标域保持原定义，但区分“完整域覆盖”和“立即让所有样本冲极限”：全域始终有非零样本，按高度×速度联合可行域加权，提高接近边界组合的采样；从容易制动/恢复的转移形状推进到更快切换。5m/s平动与3rps自旋是不同极值，不能无条件同时给满。速度组合必须满足每轮 `v ± yaw*track/2` 的轮速上限及转向侧向加速度边界，不能训练物理不可达命令。
