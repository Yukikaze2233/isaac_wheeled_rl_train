# V4.0 左右髋源网格只读对照

## 结论先行

**左右确实不同，但不能说“只有左侧重叠”。**

1. 排除两侧 nominal 髋角不完全镜像的因素后，左侧旧三个见证点仍为 base 与 thigh 源材料共同内部；精确映至右髋对应位置后，base 仍内部、右 thigh 则为空腔。不是单纯凸包填孔，也不是仅 0.415° nominal 姿态差。
2. 差异可定位到 `L_link1/R_link1 part_000` 源截面：在统一 outboard 方向下，环形安装部位**轴向台阶/大孔朝向相反**；其他组件的 XY 布局也不完全镜像。这是导出几何事实，**尚不能判断哪侧CAD设计/装配正确**。
3. **本轮独立搜到了右侧新的共同内部见证**：零位有 0.55–1.00 mm 量级的源表面深度；等角 nominal、乃至原来的不等 nominal 角也有右侧见证。旧右侧有限样本“未发现”不能作为无重叠证明。
4. 没有找到“同一整件STL/相同三角片同时重复划入 base 和 thigh”的直接证据。已定位有交叠的是 base 主连通组件000与两侧 thigh 组件000；**几何连通组件编号不是CAD部件身份**，不可据此删件或重分配。
5. `assets/urdf_v40/manifest.json` 的 `collision_validation.passed=false` 原样保留。旧邻接审查、73条历史接触诊断、训练资产、URDF、STL、碰撞策略、生成器及训练代码未改。本报告不是过滤策略批准、实体布尔认证、实机干涉结论或训练许可。

> 本轮仅新增本文件和 `reports/hip_comparison/**`。使用现有 numpy/scipy、Matplotlib Agg；未使用 Isaac、MuJoCo、图形窗口、物理积分、训练、SSH、安装或仿真步进。

### 坐标与镜像

CAD前−Y；canonical X前Y左Z上。先对齐各自**零髋关节轴**，再在髋局部轴向镜像，而非直接强行翻世界Y：

- oL=[0,0.183798094345848,−0.000836967642744012] m。
- oR=[0,−0.182798104713933,0.000832413955891113] m。
- 两侧零位从关节局部到canonical的R约为：

`R=[[-1,0,0],[0,.004553686848416338,.9999896319142947],[0,.9999896319142947,-.004553686848416338]]`

精确矩阵含浮点小量保存在JSON。

左统一坐标 hL=Rᵀ(pL−oL)=(u,v,w)，u为canonical后方，v为微倾上方，w为左侧向外。右统一坐标 hR=D Rᵀ(pR−oR)，D=diag(1,1,−1)，w同为右侧向外。

**映射pR=oR+R D Rᵀ(pL−oL)**，保留安装倾角；与简单(X,−Y,Z)不等价。左轴local −Z、右轴local +Z；qR=−qL时两侧未反射frame旋转均为R·Rz(−qL)，D与绕Z转动可交换。

当前nominal qL=0.41526541073209217，qR=−0.42250891703703075；物理角差0.00724350630493858 rad=**0.415022340149°**。分别计算等角和原nominal，不改q规避问题。下游膝/轮在开链中不影响base/thigh FK；不引入闭环，不改35–80膝合同或髋/轮continuous类型。
