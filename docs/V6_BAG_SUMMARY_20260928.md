## 参数判决

左腿 120/3 → 160/2.5，髋/膝侧角度 RMSE 0.08207/0.09025 → 0.07141/0.07910 rad；平均角误差下降约30%，角差误差下降约8%。160/3 为 0.07475/0.08274 rad，虽然共模阶跃超调下降约44–45%，扫频和力矩RMS更差，保留160/2.5。初态和温度有差别，160/3有10次执行遗漏；前79段匹配参考比较也支持保留原值。膝侧电机角差不是大小腿内角；纯PD承受气簧/重力时的静差不能直接归为模型错误。

右腿120/3 → 160/2.5，髋/膝角RMSE 0.09048/0.08920 → **0.08058/0.07976 rad**，下降10.9%/10.6%；共模误差下降30.8%，角差误差下降6.6%。力矩RMS 9.96/9.86 → 12.32/12.25 N·m，峰值29.88/30.19 N·m，40 N·m限幅占比0。去均值误差也改善，但高频速度/力矩量增加，不称全面最优；初态与热条件不同，仍需独立复核。完整repetition=1包含671420执行拍、161段、0漏拍/0丢样；repetition=0仅准备阶段因遥控停止，无运动段，排除拟合。温度由30/31升至46/48°C，必须记录而不是默认冷机。

## 训练如何消费这些数据

1. 当前bag先用于物理模型拟合与控制链复现，PPO不直接把bag当经验回放训练。旧串级bag需重现旧PI控制器，不能按新PD解释。
2. 左/右160/2.5作为当前四轴工程基线，独立录双侧复核后冻结部署增益。轮0.6按不同次序/保留轨迹录独立验收包，正常stop封存后再断电。
3. 固定车体、真实重力、完整闭链及名义气簧曲线，分别拟合轮摩擦/有效惯量与两主动轴联合响应。发送力矩与电机报告力矩只约束其各自接口，不能当独立轴端真值。
4. 按整段/姿态/运行划分开发、留出、最终验收；重复看过并据此选参的数据归开发集。MuJoCo与Isaac自由回放都通过才发布版本化模型；相关不确定性来自跨包残差。
5. 架空数据不覆盖地面轮胎摩擦、供电满载、峰值持续时间、全温域和老化。按能力补齐，不因此无限阻塞已验证基础域的S1。
