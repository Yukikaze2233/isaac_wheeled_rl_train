# V6 课程机制复审：上游证据与本轮采用规则

2026-09-28。设计补充，尚未实现可启动合同；网络35D/81D、正式20,000环境、8500次预算保持不变。本文规则并入[完整计划](V6_NEW_ASSET_TRAINING_MASTER_PLAN_20260928.md)，优先于旧“固定三档份额／默认无助跳”的描述。

## 1. 上游真实实现与不能推导的结论

核对华南虎本地源码 `b8ff79f3df855faf9dc92f4a282bd80c42649466`，来源 [wheeled-legged_RL](https://github.com/scutrobotlab/wheeled-legged_RL/tree/b8ff79f3df855faf9dc92f4a282bd80c42649466)。以下为源码能力核验，不是对其全部训练实验的复现。

- [jump_takeoff.py](../../scut-wheeled-legged-rl/source/agent_tasks/agent_tasks/direct/wheelbipe/state_machines/jump_takeoff.py)：`_get_assist_probability` 与 `_get_assist_force_scale` 确实分别插值，支持 probability/force/both；力幅还可有独立起止迭代。值得采用，但仅凭函数存在不能证明某次公开模型实际启用双衰减并完成无辅助验收。
- 同文件 `_sample_peak_height_from_bins` 实际读 `range` 与 `prob`（兼容 `probability`），按归一化概率抽样；这里**没有读取 weight，也没有按迭代或成功率自动改 bin 概率**。`_sample_ballistic_peak` 另有迭代驱动的范围插值，但 bins 开启后优先采 bins，插值的 peak_cfg 不参与该路径。掌握后转移份额是我们要新增的课程规则。
- [V14 env_cfg.py](../../scut-wheeled-legged-rl/source/agent_tasks/agent_tasks/direct/wheelbipe/wheelbipe_V14/env_cfg.py) 命令驻留为5–15秒；1–8秒来自旧 `wheelbipe25_v3/env_cfg.py`。两者都不自动等于跳跃请求的触发间隔。
- 抽查公开 `rough_rotation_stair/2026-07-30_09-16-27/params/env.yaml`，trajectory、bins、assist均为 `enabled: false`。这不说明上游从未使用，只说明不能把该配置当作“这四项全在用”的证据。
- 我们的 [env.py](../src/wheeled_tasks/chassis/env.py) 已在reset时采 `motor_strength` 和 `spring_strength` 并于回合内保持；跨回合独立抽样与回合内持续降级并不矛盾。缺的是命名的不对称故障、发生时刻、严重度与持续时间，而非“从零补上持续随机化”。

## 2. 九项建议的采用结论

|建议|判定|采用方式／需要纠正处|
|---|---|---|
|助跳概率×力度渐退|采用，有价值|S5显式限时辅助、无辅助对照和强制清零；不能把有辅助离地解释为策略起跳已学会|
|跳高bin晋级重分配|采用|新增可审计分配器；不是上游该函数已有自动课程，保留每档最低份额|
|所有课程统一全局迭代单调推进|部分采用|消除episode局部时钟和隐式回退；预算时钟与学习/课程时钟分离，能力gate决定解锁|
|命令驻留1–8秒→0.5–4秒|采用为我方候选|连续命令与技能请求分开；保留足够长的实际到速驻留，快请求不能重置正在执行的跳跃|
|边缘状态出生10–15%|采用10%起点|从物理有效轨迹抽取，区分边缘自救与全倒地R0；不能随机拼出闭链不成立的关节姿态|
|请求时序课程|采用|冻结间隔、重复、取消、忙时处理、种子和留出分布；提前在S4/S5训练|
|持续降级5%|采用为工程压力样本|复用回合恒定随机化，新增单侧模式和持续区间；未实测的严重度不能称已辨识|
|高度×速度危险边界过采样|采用|在真实可达域内边界2倍权重，按有效驻留秒数检查覆盖，不盲给高×快固定30%|
|先纯离散40%后连续|不采用纯离散硬切|从开始覆盖全域；前200次80%固定档＋20%连续，之后50/50。400次只是拍定预算，不是学会依据|

## 3. 时钟、恢复和晋级

定义三个显式字段：`budget_updates_consumed`（所有实际优化消费，含critic-only、重试、诊断所属账本，不因回滚退还）；`stage_actor_updates`（本阶段学习谱系上完成的actor更新，跨episode）；`curriculum_revision`（已确认的采样/目标域版本，附确认评测ID）。

辅助和固定时间表使用 `stage_actor_updates`，不使用episode长度、墙钟或critic预热次数。正常向前学习时单调；高档解锁同时需要能力gate。预算耗尽仍未解锁时如实停段，不能用增大迭代数字硬推难度。

checkpoint保存actor/critic/optimizer/RNG、全部课程计数、概率表、辅助配置和技能状态语义。exact resume恢复同一套；gate回滚恢复该checkpoint的课程状态，但**预算消费时钟不回退**。若坚持保留更晚的难度版本，必须显式建立迁移/修复分支、重评恢复策略，并继续扣既有预算，不能同时声称“课程永不回退”和“整套checkpoint原样恢复”。短期训练成功率只作诊断，不能逐episode升降难度导致振荡。

## 4. S5 高跳与助跳

### 高度的物理含义与观测

目标扩展为COM相对真实释放点上升 **3/6/10/15/20/25/30cm**。15–30cm是新增设计档位，需在G0/G1核实能量、速度—力矩、行程、落地和接触裕量；不把30cm写成已证明能力或最终物理极限。更高档可按同一机制另版扩展。上游root绝对peak height 0.45–0.65m不能直接解读为45–65cm跳高。

静止与行进分别验收，0.4m/s＋10cm已有目标保留；高档行进组合先核实可达域。全域可达表冻结后各有效档位从S5开始保持非零覆盖，学习重心逐档上移。每个档内也采连续中间值；固定验收点不会随训练抽样概率变化。

网络维数不变，但跳高目标必须可由现有命令/模式/相位输入区分。G0须验证不同跳高经现有高度参考和相位轨迹能在起跳前被actor辨识，RMCS复现同一接口；不能只在reward背后抽取隐藏顶点目标，也不能偷偷给actor加一个维度。若现有语义无法表达，先形成显式接口迁移方案再启用多目标训练，不声称已经接线。

### 辅助窗口

S5前0–300次actor更新使用 `t=clip(stage_actor_updates/300,0,1)`，`p=0.8-0.6t`、`scale=1-t`。在300次及以后显式设置 `enabled=false,p=0,scale=0`；p到0.2而force到0本已无物理帮助，再清零标志可消除统计歧义。至少20%跳跃从第一轮就完全无辅助。辅助不扩增S5的2000次总预算。

采用蹬伸支撑期有界竖直外力的单一路径；不默认直接改root速度、不在腾空继续托举。`F0`、持续窗口、最大总冲量按新资产质量与无辅助可用驱动确定并在G1冻结，1.0是相对尺度，不是1N；未冻结不得启动该课程。把无辅助、力辅助、合法预载冷启动分别记录，包含每次实际冲量和辅助功；辅助样本仍可用于PPO，但不进入能力通过统计。每40次固定无辅助探针，从第300次后的正式检查点起才允许S5晋级。

保留80次零离地检查，分别检查辅助/无辅助有效尝试数。辅助也不离地提示参考、接触、驱动或探索问题；只有辅助能跳说明迁移尚未完成。不能因“加过助跳”删除诊断，也不能让策略依赖辅助力刷高度收益。

### bin分配

在全部七档已机械验证的情况下，初始概率依次为 **30/25/20/10/5/5/5%**；不是七档平均分。若某档尚无可达证据，标记未开放，报告支持域，不暗改验收目标。每次独立无辅助确认评测通过一个当前学习档，下一次reset起将该档超过5%下限的份额转移一半给下一档：`transfer=max(p_i-0.05,0)/2`；每档每个修订只触发一次，已达最高档则不转移。记录归一化前后概率、有效样本量、触发评测和修订号；回归失败走gate，不在每个episode自动逆向搬回。

bin概率只改变采样；reward核宽、容差、终止定义不跟着概率暗变。每档正常站立起始和静止/行进组合均有显式覆盖，辅助关闭后的成绩逐档报告。

## 5. S1–S6 采样与时序

- **高度教学**：S1前200次actor更新按80%固定高度档＋20%连续值；随后50/50。固定候选档明确为0.23/0.26/0.29/0.305/0.32/0.37/0.43m，须全在D内；不要用“.23每.03到.43七档”的不一致写法。均衡上/下行，端点和中间值独立验收。200次为配额变化点，不是能力通过点。
- **高度×速度联合域**：S2运动池明确20%用于非名义高度组合（占50%全域运动池的20%，即全体回合10%）。在D内先按高度/速度/yaw符号与档位分层，再对到可达边界归一化距离≤10%的样本赋2倍权重，归一化抽样；其余1倍。低×快、高×快都检查覆盖，不把全量压到不可能的组合。独立高度10%主要承载高度教学，不能拿它替代运动池联合训练。部署可达域不得依赖未提供的前探感知。
- **边缘初态**：S3起在可恢复且与当前任务兼容的回合中10%采用 `recovery_born`，达到固定门后另版可增至15%。这是初态维度，不与主表技能份额重复相加；报告每技能实际比例与总体实现比例。状态来自真实仿真轨迹库的推扰后、低头/后仰、支撑切换、落地反弹，保存整机状态、闭链约束、接触一致性和观测历史。不得用任意关节拼接破坏闭链；不人为把大倾角失败一律延迟0.5秒。全倒扣或卡住状态走R0脚本，普通RL练其有效接管状态。
- **持续降级**：S3起5%回合为命名单侧压力模式，属于原≤50%扰动样本内，不能额外叠加比例。复用reset固定参数，记录侧别、严重度、发生/解除时刻；可分别覆盖单腿力矩折减、单轮低摩擦/失去接触、气簧力偏差。低摩擦改变接触属性，悬空改变真实支撑，不能都用motor_strength替代。先单因素，严重度由D/G1或明确工程先验冻结。30秒持续需要≥30秒回合，20分钟泄压只可作为恒定参数近似，短回合不证明长期带伤适应；本轮无记忆网络也不声称在线辨识隐藏故障。正式普通回归保持，故障结果单列，不纳入已验收能力。
- **连续命令**：S4/S5候选 `Uniform(1,8)s`；S6采用80% `Uniform(0.5,4)s`＋20% `Uniform(4,8)s`，为快速切换与充分到速均留样本。速度/高度参考仍限斜率，统计原始请求、有效参考和真实目标驻留。固定验收用完整驻留协议，不被频繁取消稀释。
- **技能请求**：单独生成事件。S4/S5以20%回合练时序压力，其余完成一次技能再训练下一次；S6压力回合升至50%。压力回合候选请求间隔 `Uniform(0.5,4)s`，每次事件10%重复、10%取消、80%新请求；三项和为100%，只在合法语义下解释。正常回合在上次技能结束并稳定后等 `Uniform(1,8)s` 再请求。忙时重复不重置相位；起跳提交前取消可回到站立，蹬伸/腾空后取消只影响后续任务，当前完成落地恢复。请求接受/拒绝/合并与原因全部记录。若RMCS当前没有对应协议，先落实同一语义再训练，不用仿真专属队列制造能力。

## 6. 稠密动态reward与自起接管

“动态”指当前可部署请求和相位决定参考轨迹；奖励形状与系数在冻结合同内保持明确。预载、蹬伸、腾空姿态、落地减速、恢复分别给过程反馈，广域项加精度项保留；达成/离地等离散事件保留一次性奖惩，不强行把所有安全与成功判据软化为稠密分数。先比较完整回报反例，再用采样优势/PPO行为检查，不把解析导数当收敛保证。

自起以 [RMCS当前实现说明](../../../RMCS/docs/zh-cn/wheel_leg_self_righting_implementation_20260927.md) 为权威，旧两份设计仅作历史。R0保留200Hz脚本状态机、50Hz影子RL、200ms模型侧力矩混合、接管后至少1秒且连续1秒条件稳定后才放开运动请求；这些频率不替代本轮拟迁移的1kHz下层PD。双下0xFD、双中0xFB→0xFC、禁止重复设零、真实标定门禁由原硬件链负责，课程不绕过。

当前恢复配置门禁仍关闭，未完成同资产C++闭环验证；原105°零点回归在劈叉等姿态有失败，不能宣称可稳定自起。训练接管库应来自当前状态机/观测器的有效出口，并覆盖混合期与运动保持期，包含条件接触估计误差；不把半跪、倒扣直接扔给仅练平衡的RL后将失败算作普通课程不可学。

双级高台阶作为C11独立目标保留：“第一层200mm、第二层250mm”的两种几何（顶面200/250mm，或两次上升200/250mm最终450mm）待用户确认，同时须明确踏面深度、宽度与退出路线。确认前不据任一解释生成正式地形或预算通过项。
