# 腿侧响应回放：共同假设与剩余阻塞项

2026-09-29。本次只读源代码、封存资产、既有导出与录包附件，补做七个姿态的静态虚功检查和旧 PI 保持段负载检查；没有改回放母类、合同、拟合参数，没有新增优化或上机操作。数值与输入 SHA256 在 [static_checks.json](../reports/v6_leg_response_blockers_20260929/static_checks.json)。

**现有证据没有找到一个确定的“髋膝映射反了”代码错误，但已证明不能把残差全部交给电机 lag/armature。** 窄域 PD 改善与旧 PI 宽域失败共用尚未独立核验的零位、气簧负载、轴端力矩定标和支架姿态。腿侧候选仍不进入训练；这不等于现有 bag 无用，也不等于必须先重录。

## 1. 坐标与关节映射：软件自洽，实物零位未封存认证

`identify_pair_dynamics.Replay` 和独立 `LegacyReplay` 都采用：

```text
q_old = q_ref_model - position_error_model = model_sign*q_api + model_offset
q_v6 = -q_old; dq_v6 = -model_sign*dq_api; tau_v6 = -model_sign*tau_api
```

参考配置的四轴顺序是 `[LH,LK,RH,RK]`；硬件 DM 配置数组是 `[LH,RH,LK,RK]`。控制与记录已按所选两轴取值，左为 `L_joint1/LL_joint1`，右为 `R_joint1/RR_joint1`。这两个都是车体上的主动轴；辅助轴不是串联膝铰链，二者角差也不是物理内膝角。回放保留真实闭链并由闭链求被动膝角，没有把辅助电机当作被动膝轴直接施力。旧包两种位置重建路径的最大差为 `4.45e-16 rad`；速度和力矩同步翻号，虚功不因坐标变化而翻转。

`coordinate_mapping.json` 明确主动轴从 V5 到 V6 的符号为 −1、无额外根部 Rz90；同时明确 `encoder_zero_or_hardware_binding: not_inferred_from_asset`。用文档“电机 raw=0 时大腿朝上、内角105°”的**假设**代入：左 `(1.6,2.93)`、右 `(-1.6,-2.93)`，编译闭链重建出内角 `105.0217°/105.0212°`，大腿方向 Z 分量 `0.99956`。因此没有支持再整体反号或再加90°的证据。这个检查是配置与 CAD 的一致性，不能替代当时实车执行零位标定的记录。

旧 PI 013446、左 PD 073044、右 PD 144606 的原 `profile.yaml` 都保留 `model_sign=[1,1,1,1]`、`model_offset=[-1.6,-2.93,1.6,2.93]`；也都声明旧 `v5_232mm` 资产 SHA `dbec8e…`。回放使用的 V6 stop105 SHA 是 `875fa7…`。这说明归档元数据没有完成 V6 实物绑定，**不能据此断言硬件换过，更不能断言物理零位已相同**。用户确认机械尺寸不变是有效背景，但仍需将具体录包与实物装配、标定记录对应起来。

## 2. 气弹簧：施力方向正确，厂家曲线拟合不等于实机负载辨识

当前回放使用封存 `fit_10mpa.json`：`F(u)=280+122.73591849*u²+53.96980441*u³ N`，`u=compression/0.08`。其来源是厂家9/12 MPa曲线读数拟合与10 MPa插值；文件仍写明 `physical_force_model_identified=false`、安装参考未实测识别、摩擦/滞回未识别。`installation.json` 的232 mm全伸销距与80 mm行程沿用用户确认，`gas_spring_binding.json` 的 `reference_hardware_verified=false` 仍需保留。

回放令 `compression=0.0697271801-q_slide`，给 slide 的正向 motor（gear=1）施加正力。七点有限差分得到 `d(pin_distance)/d(q_slide)≈+1`，因此正力确实伸长销距、减小压缩，不是符号写反。左主动轴的弹簧广义力约为 `[-12,+12] N·m`，右侧镜像反号；由闭链切向投影所得方向与增大内膝角一致。

三个旧 PI 广域检查点的内角为77.33°、89.10°、97.22°，对应压缩43.83、33.37、26.25 mm，力为325.71、305.28、295.12 N，主动轴力矩幅值约13.53、13.19、12.70 N·m。都在拟合域内，本次这些点的差异不是90–100%行程外推造成的。但实物气压、缸体摩擦、方向滞回、安装长度误差及机构关节摩擦没有因此消失。

另查旧 PI 全部61段，沿用 `static_load_audit` 规则：参考恒定、段长至少1 s、末500 ms速度 RMS不超过0.08 rad/s。31段符合；排除名义内角≥104°后有30段，均使能请求为真、499/500行 scope=1。每窗包含的1行 scope=0不冒充已确认交付。其实际角变化最大仅髋0.00229 rad、辅助轴0.000381 rad。

这30段的 `host_command − (CAD gravity + spring hold)` 残差中位数是 **`[+3.888,-6.116] N·m`**。例如段2内角99.63°，预测保持 `[13.318,-13.423]`，命令均值 `[18.891,-20.000] N·m`；段44内角90.84°，预测 `[12.346,-12.122]`，命令 `[13.368,-20.000]`。反馈力矩估计接近命令，但它仍使用驱动自身定标，不能当作独立轴端力传感器。

这些是准静态**命令平衡**差，不是已测出的纯摩擦值；它可能混合气簧、静摩擦、未记录接触、力矩刻度及零位误差。持续静止残差不能靠增加惯量或毫秒级一阶响应时间解释。左候选1.30 N·m左右的辅助轴 frictionloss也未解释约6 N·m的中位差。先校核负载与输入定标，才有依据分辨电机动态。

## 3. 架空重力：没有漏掉重力，但默认了未验证的支架姿态

两个 MuJoCo 回放都移除自由根和地面，固定 `base quat=(1,0,0,0)`、`g=(0,0,-9.81)`；保留受试整腿连杆、轮组、弹簧质量与约束。另一条失能腿在理想刚性支架下移除，不影响受试腿动力学；真实支架若晃动，这个假设就不再充分。所有碰撞几何也被移除，仅余关节行程约束，因此夹具接触、线缆牵扯或实物局部卡滞不会自动出现。

原 profile 明确要求用 IMU四元数与静止加速度核查支架姿态；目前三个回放 NPZ 均未导出这些字段。左右 PD 原始 MCAP在本机，随包消息定义包含 `imu_quaternion_xyzw`、加速度、时标，**可以优先从既有 bag 补导出**；“字段存在”不保证数据有效或外参正确，要再核对有限值、鲜度、静止比力和安装方向。旧 PI 原始 MCAP本轮未在本机找到，不能用后一次支架姿态代替它。

按当前 CAD质量，对上述三个广域姿态分别把重力投到 XYZ 并求任意方向的上界，各主动轴静态重力幅值最多约 **1.75–1.81 / 1.09–1.15 N·m**，明显小于弹簧约13 N·m。重力方向应修正，但在这些姿态与固定 CAD质量前提下，单纯旋转重力方向不是解释全部6–8 N·m膝侧差异的充分条件。CAD的质量/惯量来源文件也标记 `hardware_identified=false`；本轮没有把 CAD惯量当作实测真值。

## 4. 力矩输入：正确的端点仍是待核验先验

旧 PI 原控制器是1 kHz位置—速度PI串级、20 N·m上限；回放直接使用已导出的 host torque，**没有套160/2.5 PD**。所有 active 的 `tau_cmd_api` 都等于记录 preclip 的±20 N·m裁剪。原 profile 将反馈参考声明为“DM reducer-output Nm assumed pending scale check”。当前母类输出轴 motor gear=1，没有再乘9或9²；仅凭电机有9:1减速比不能在此处重复折算。

左 PD 原字节审计已证实电机内部 Kp/Kd为0，主机执行160/2.5、1 kHz PD，50 Hz参考保持，再提交纯力矩 MIT；1343个0xFC心跳单独记账。`Replay` 对系统帧沿用上一次有限扭矩，这是输入保持假设，不是CAN接收ACK。旧 PI导出缺帧字节/tx_kind，所以 `LegacyReplay` 只能声明host command，不能升级为已交付MIT力矩。输出轴力矩尺度、寄存器P/V/T范围与驱动内定标，仍需要独立证据。

配置与协议的数值一致性可以用现有包继续检查；“驱动报告力矩≈命令力矩”不能独立验证实际轴端力矩，因为二者可能共用同一刻度。若现有随包寄存器读回/台架标定找不到，就需要最小限度的设备参数核验或外部载荷标定，而不是用拟合 gain任意修平曲线。

## 5. 止挡与观测：模型接触不能当作实物接触标签

窄域候选在名义实测内角<104°时仍大量碰仿真105°上止挡；旧 PI宽域200 ms检验则18/22窗碰到40°下止挡。两者不是同一边界失效，不能只放宽上限解决。下止挡接触是模型预测出现强烈错误运动的结果；也不能仅由此把真实下限改掉。105°是用户确认的标定角和机械限位，106–107°可能包含零位、柔性与读数误差，当前 `stop105` 文件也写明 effective-stop/zero separation 尚未完成。

旧 PI名义角重建覆盖75.69–107.79°，比当前 PD拟合窗宽；但两者内角都由相同未实测校准的CAD映射计算，不能称“独立测得的接触真值”。七点初始闭链误差≤`4.6e-15 m`、200 ms仿真无数值警告，只证明几何/数值求解可用，不证明力模型正确。反馈缓存重复、尤其右腿约10 ms结构的8%重复，另见[时序审计](V6_TRANSPORT_BAG_AUDIT_20260929.md)；这些观测机制应进入对齐检查，却不能替代静态负载校准。
