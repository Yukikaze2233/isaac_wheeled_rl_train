# V5 完整专项课程：SCUT 单策略路线

## 运行合同

入口：`scripts/run_full_chassis.py`；计划：`contracts/v5_scut_skills_v3.json`。
21 项技能分成 32 个专项难度阶段，最后接综合和鲁棒综合，共 34 阶段。
每个专项阶段只有一个训练组；回归评测包含原始七案例，以及各已通过技能的最近难度。
同一策略接续扩展，不做独立专家权重平均或实机多模型切换。

华南虎参考版本：`scutrobotlab/wheeled-legged_RL@b8ff79f3df855faf9dc92f4a282bd80c42649466`。
复用的是 V14 普通 PPO 的任务组织、参考系速度变换和空中/落地场景语义。
参考系变换适配代码及出处位于 `skill_commands.py`，许可证见 `SCUT_LICENSE.txt`。
V5 仍使用已验证的 PhysX 闭链、RSL-RL 5.5.1、230D 历史观测 actor 和六电机接口，
以便继承已评测的 19179 更新权重。这不是原样运行华南虎 35D 部署网络。

## 功能与场景

| 类别 | 独立技能 | 本轮计划范围 |
|---|---|---|
| 基础 | 站立、高度、前进、后退、启停换向、旋转、弧线、小陀螺平移、抗扰 | 高度 0.29–0.32m；直线逐档到 ±3m/s；旋转逐档到 ±8rad/s；推扰 0.15m/s 速度增量 |
| 地形 | 上坡、下坡、横坡、粗糙面、上单阶、下单阶、上连续阶、下连续阶 | 坡 5°；粗糙高差 2cm；上阶 3→6cm；下阶 5→10cm；连续三级、级高 2cm |
| 空中 | 空中姿态、落地、原地跳、行进跳 | 空中 reset 6/15cm；跳跃过程参考增高 6→10cm；行进跳要求前进至少 15cm |
| 综合 | 技能混合、材质切换、鲁棒混合 | 材质摩擦 0.3–0.7；观测/动作延迟 0–20ms；噪声、电机强度 0.85–1.0、气簧力 0.9–1.1 |

这些是训练目标，不是能力通过声明。气簧安装、惯量和执行器参数仍采用记录在案的研究基准。
当前无实物云台，小陀螺平移使用固定虚拟云台参考航向；用旋转周期尺度的速度跟踪奖励，
评测参考系平均速度误差，避免要求非完整约束轮对瞬时实现侧向速度。
复杂地形、跃迁能力均须经过真实物理回合验收。

主动跳跃是 V5 扩展：华南虎当前公开注册配置没有开启主动起跳。
起跳时不施加抬升外力、不直接修改向上速度；空中初始化只用于空中/落地专项。
跳跃同时检查双轮离地时长、正向释放速度、基座参考高度、真实整机质心腾空上升及落地稳定。
质心上升从检测到腾空时开始计算，门槛分别为 2/6cm；不能把伸腿抬高基座当作质心腾空上升。

## 课程与退化保护

1. 从通过基础评测的 mixed 19179 checkpoint 迁移，原始 SHA256：
   `51260d0c1518c697bbcf98d07af392b70161b401fc57d82d32f6adfd22137e30`。
2. 每阶段先评测；两个固定种子均通过可跳过该阶段训练。
3. 未通过则专项 PPO，每 250 更新退出 Kit，顺序运行独立评测。
4. 新技能和旧技能回归同时通过才接续下一阶段；回归连续三块失败则保留已通过产物并暂停。
5. 旧回归案例保存各自地形尺寸、命令轨迹、跳跃参数和时长，不随新阶段难度偷偷改变。
6. 最终综合分布包含全部专项和材质切换；鲁棒分布同时评测干净与扰动案例。

每案例每种子 4 回合，两个种子用于训练门控；该小样本门控不是最终百回合发布验收。
每阶段有独立更新上限，整个队列另有 72h 墙钟上限，包括评测与进程重启。
该预算不保证所有阶段均能通过。

新任务使用 fresh critic/optimizer，前 50 次更新仅拟合 critic，再更新 actor。
学习率固定 3e-5；critic 中连续轮角置零，但不改变 actor 输入维度。
这些是本轮训练配置，不能据此宣称已确定上一轮退化的唯一根因。

物理步长 1ms、策略周期 10ms，TGS 64/32。复杂地形碰撞可能产生闭链瞬态残差；
超过 3mm 的环境计为 `closure_gap` 失败并重置，不能计为成功或获得成功奖金。
保留该门槛、逐组残差峰值和失败计数，避免一个失败回合退出整个训练队列。
非有限物理状态仍中止进程。
高速场景的长走廊使用 8m 地面段拼接：GPU PhysX 对单个 80m 薄盒的接触表现与原场地不同，
有界 A/B 已确认它会破坏轮接触；分段后恢复正常轮承重。原始调试记录在
`reports/v5_scut_debug_04.log`、`v5_scut_debug_05.log`、`v5_scut_debug_06.log`。

## 产物与监控

- `progress.json`：当前阶段、累计更新、阶段更新、训练/评测子进程。
- `stage_*/block_*`：checkpoint、实际电机力矩、行为计数、TensorBoard 与源码快照。
- `stage_*/evaluation_*`：固定评测、代表轨迹、合同及源文件哈希。
- `accepted_policy.pt`、`accepted_policy.onnx` 及各自合同 sidecar：最近通过阶段的产物。
- `artifact_selection.json`：明确部署产物与最后通过阶段。
- `model_final.pt`、`policy.onnx`：最新候选，不能仅凭文件名作为通过模型部署。
- job 退出后生成 `delivery.tar.gz` 与逐文件 SHA256；本机 watcher 自动回收并校验。

正式回执与实时查询命令在部署完成后记录到 `docs/evidence/`。

## 上一轮基础训练结论

`v5-locomotion-v2` 在 1500 更新后触发 `regression_hold_best_preserved`。
它是 stand/translate/rotate 共享策略训练，不是 stand-only。
三个 block 合同相同，固定评测均未通过，只有初始 19179 权重通过。
代表轨迹显示最终站立高度偏低到约 225–232mm，而非 61mm 幅度的高度振荡。
原始基线被保留，但旧顶层 ONNX 对应最后失败块；本轮显式区分 accepted 和 latest。
