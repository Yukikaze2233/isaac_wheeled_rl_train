# 新底盘完整训练：多场地、小陀螺、上下台阶与落地

状态：**需求与实现规格，尚未启用这些新场景**。只使用用户确认的新两级四杆几何。`model/纯底盘/chassis.usdc`目前是几何资产，仍需补齐质量/驱动映射及闭环动力学验证。

本规格扩展[修复后基础设计](ROUND4_REPAIRED_TRAINING_SPEC.md)：最初30000更新作为基础区块，完整技能按100000更新分段投入。零点任务继续等待修复动力学就绪，不能用旧七刚体环境或动画替代。

## 1. 上游实际启用的机制

- 华南虎V14 Rough任务包含小台阶、低坡/反坡、阶梯坡、平地和随机起伏，使用地面相对高度。
- 华南虎`FlatEnvCfg_v1`腾空落地分支启用`ctrl_mode_obs`：normal/stair/slope/recover/jump/height_target/state_time，并开启airborne状态机和机体/轮子高度扫描。它不是仅扩大vx/wz范围。
- 复旦jump任务单独启用flight、encourage_jump、base_height_flight、leg_tuck、takeoff_extend、line_z等奖励，按接触/腾空条件处理动作；plane分支不能被称为已启用跳跃。
- 复旦jump的世界z目标0.65m、虚拟腿长0.16/0.31m属于其模型与奖励定义，不复制到V40。我们的目标必须关联平台高度、轮/杆件净空和实际可达性。

参考任务组织与接触阶段，不整套搬入两家的机构参数、奖励、回弹或终止定义。

## 2. 场地和难度

以下均为首批候选，不是已验证能力。台阶/落差指真实支撑表面的高差。

| 场景 | 初始候选 | 后续验证 |
|---|---|---|
| 多材质平地 | 有效动摩擦0.4–0.6，静摩擦不低于动摩擦，约30%名义环境 | 通过后扩0.3–0.8；记录合成模式和实际shape读回 |
| 材质交界 | 正常附着→低附着→正常附着 | 左右轮先后跨界、制动、转向；不以每帧随机μ冒充空间变化 |
| 缓坡/横坡 | 0–5°，双向和横向经过 | 通过后评估10°，包含坡上站立、起停和高度调节 |
| 微起伏 | 例如2–5mm | 逐步扩大，验证网格分辨率、碰撞cooking和高度reference |
| 低台阶滚越 | 5–10mm、低速、单阶 | 连续阶单独评估，不把滚越记成主动跳跃 |
| 跳上台阶 | 先20–30mm，再评估50mm | 起跳点、平台和落点明确；更高台阶先检查力矩/功率和净空 |
| 下台阶与落差 | 20–50mm，先低速滚落 | 再评估100mm；更大落差根据落地能量和压缩行程验证 |
| 平地小陀螺 | yaw 2→4→6→8rad/s | 再单独评估12.57rad/s≈120rpm，双向、启动和刹停均覆盖 |

高速小陀螺先在平地独立训练。坡面、台阶、低附着和腾空中的旋转先降低速度，不叠加全部最大难度。物理解算允许真实滑移，不能把轮子用脚本强制粘在地面上。

## 3. 接触阶段与奖励

采用可观测阶段`GROUND → TAKEOFF → FLIGHT → LANDING → RECOVERY → GROUND`；下台阶可从GROUND直接进入FLIGHT。

| 阶段 | 主要目标 |
|---|---|
| GROUND | 站立、行驶、旋转、低阶滚越；跟踪地面高度/速度；正常接地且无跳跃请求、全零速度命令时才启用安静轮速正则 |
| TAKEOFF | 在支撑接触下完成请求的起跳冲量，控制能耗与真实关节/执行器边界；不持续奖励无任务乱跳 |
| FLIGHT | 姿态、角速度、腿部净空和预期落点；关闭贴地高度保持、静止轮速收敛及必须双轮触地的目标 |
| LANDING | 首次真实地面接触后吸能、适配落地切向速度，控制反弹、倾覆和饱和；首次接触不等于成功 |
| RECOVERY | 恢复目标高度/姿态和命令跟踪，连续保持指定窗口后才判任务完成 |

阶段判别需要带地面/平台身份的接触、运动状态及滞回/防抖，自碰撞净力不能代替轮地接触。全程保留nonfinite、真实机械越界和明确失败事件；正常腾空不判摔倒，也不能为了跳跃取消全部失败终止。

现有vertical velocity、地面高度、动作平滑等项须按阶段审查。空中转轮可能参与姿态调整，不能无条件要求轮速为零。侧向冲击先在GROUND训练；学会基本落地后再单独扩展空中扰动。

## 4. 新观测与命令合同

旧125维actor缺少完整任务/地形和飞行状态信息，不能默认直接承载所有新技能。首段从零前先定义统一新接口：

1. 地面vx/wz、站立高度、跳跃请求及目标平台相关量；普通蹲起和主动跳跃语义不同。
2. 可部署的姿态、角速度、必要的线速度/竖直运动估计、轮接触估计与阶段时间。明确真机来源，不能把仿真真值直接当作已具备传感器。
3. 台阶信息来自前视感知，或上层明确给定障碍/跳跃触发。感知方案尚未确认时，不宣称自主识别未知台阶；上层触发仍可训练低层起跳/落地技能。
4. critic可使用仿真特权信息，但critic看到地形不等于actor具备地形感知。

普通MLP/PPO仍为首选基线。输入维数、历史、尺度及六个独立控制坐标要在新合同中冻结，并适配ONNX/回放；旧`[1,125]→[1,6]`链路成功不等于新全任务接口已验证。

## 5. 完整100000更新预算

基准1024env、48步rollout，同一修复模型、统一新接口逐段训练；首段从零，后续使用验证后的父checkpoint。

| 阶段 | 更新预算 | 累计 | 核心内容 |
|---|---:|---:|---|
| 1 基础站立/起停 | 10000 | 10000 | 新机构平衡、安静轮速、H_valid内多高度、正反行驶 |
| 2 多材质/缓坡/起伏 | 15000 | 25000 | 摩擦变化、坡上支撑、相对高度、停止和恢复 |
| 3 高速直行/小陀螺 | 20000 | 45000 | 3m/s直行主目标、4m/s扩展；yaw逐级到8rad/s，再条件评估120rpm |
| 4 主动上台阶 | 20000 | 65000 | 低阶滚越→受控起跳→平台落地 |
| 5 下台阶/落地恢复 | 20000 | 85000 | 滚落/跳下、吸能、减小反弹并恢复跟踪 |
| 6 混合巩固 | 15000 | 100000 | 场景串联、材质交界、留出组合和较长任务 |

**零点任务仍只安排首个30000更新区块**，即阶段1、2及阶段3的前5000次；不代表首夜已经执行全部跳跃和落地课程。后续区块依据回收评估及实现状态衔接。

成熟阶段至少保留40%已掌握的基础场景，包括明确的静止样本。新场景逐步增加，晋级看独立成功率与基础能力退化，不能只看reward。空间材质、地形、速度、跳跃高度先逐项扩展再组合。

## 6. 按技能验收

- **站立**：连续60秒无timeout重置，多高度；姿态/高度、实际与目标轮速、RMS/P95、净漂移与路程。
- **材质/坡面**：分摩擦/坡度的起停、转向、制动距离、轮地接触点纵横滑移及材料读回；净力候选不是滑移率。
- **小陀螺**：实际yaw稳态误差、中心漂移、轮速/力矩/功率饱和、启动和刹停恢复；命令框120rpm不算实测达到。
- **上台阶**：到达指定上平台，取得正确支撑并稳定保持；记录碰边、跌落、非轮支撑、落点误差和能耗。
- **下台阶/落地**：到达下平台并恢复，记录冲击峰值/冲量、反弹、姿态过冲及恢复时间。峰力比较须固定物理步长与采样方式。
- **恢复**：目标2秒内进入预定义误差带并保持1秒；给出独立试验数和置信区间。reset或观测不完整不能算成功。

物理步长能否解析落地冲击需随新资产验证；不能以动画画面或未经接触验证的几何滑动做物理验收。

## 7. 实施状态与依据

修复动力学、真实驱动/质量参数、地面接触身份、地形/高度reference、模式/观测、跳跃落地奖励、课程及新ONNX接口仍需实现或适配。现有平地摩擦/velocity-push草稿不是完整环境。定时器继续等待真实就绪证据，不会因为几何预览能动就置`physics_ready=true`。
