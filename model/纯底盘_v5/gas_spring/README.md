# BKB 氮气弹簧：10 MPa 图示曲线拟合

依据用户提供的 BBK-JINGBA「BKB 系列 450N」目录第 18 页，按 9/12 MPa 两条曲线插值至
用户指定的 **10 MPa**。15 MPa 曲线作为独立缩放交叉检查。这里是目录图的工程近似，非实测辨识。

## 结果

令 `s` 为从完全伸出位置开始的压缩量，单位 m；按箭头所指型号候选
`BKB0.45-080-205`，额定行程 `S=0.080 m`，`u=s/S`：

```text
F(s) = 280 + 122.735918491 u² + 53.969804409 u³   [N]
u = s / 0.080
```

`F` 是使弹簧伸长的推力大小；若广义坐标取压缩量 s，则对应广义力是 `-F`。
拟合/默认使用域为 `0≤u≤0.9`，即 **0–72 mm**，保留最后 10% 额定行程。
这不是把机械行程改成 72 mm；80 mm 的真实硬止挡与 72–80 mm 的力曲线另行处理，当前接口不隐式外推。

| 压缩量 | 推力 |
|---:|---:|
| 0 mm | 280.0 N |
| 20 mm | 288.5 N |
| 40 mm | 317.4 N |
| 60 mm | 371.8 N |
| 72 mm | 418.8 N |

独立量纲检查：φ6 mm 杆的面积乘 10 MPa 约为 **282.74 N**，与图中零行程插值得到的 280 N 接近。
15 MPa 曲线按压力比例缩放后的最大差约 **9.22 N**，在本轮约 ±10 N 的读图量级内。

## 拟合方法和精度

`catalogue_points.json` 是从聊天图片**人工近似读数**的三组点，按 5 N 左右粒度记录，
不是对原始图片像素自动提取的结果。各压力曲线固定目录标注的起始力 250/340/430 N，
用非负系数三次多项式拟合；然后 `F10=(2 F9+F12)/3`。
拟合函数非负、单调不减，不会出现普通高阶拟合在端点掉头。

对近似插值点的 RMSE 为 0.81 N，**这仅是数学拟合残差，不代表实际弹簧达到 0.81 N 精度**。
人工读图误差暂按约 ±10 N 看待；不是统计置信区间或厂家公差。近零处的零斜率来自曲线形状拟合，
不能解释成实际气体弹簧初始刚度必为零。后续若得到原始矢量图或测力数据，应重新拟合。

## 尚需核实的安装信息

1. 箭头对应型号是否确为 **080-205 / 80 mm 行程**。
2. 横轴仅印「行程 0–100」，没有 `%`；当前按全系列通用的行程百分比解释。
3. 目录总长 **205 mm**、最短长度 **125 mm** 不是自动等于安装后的两销中心距。
   V5 源零位两销中心距为 **162.27282 mm**；需要全伸时销距或接头偏置才能计算预压缩量。
4. 动态阻尼、密封摩擦、伸缩滞回未由单条静态曲线给出，不从这张图反推这些参数。

## 文件与复现

- `catalogue_points.json`：原始近似读数、单位假设、用户压力。
- `fit_10mpa.json`：系数、拟合范围、来源哈希和未确认项。
- `force_table_10mpa.csv`、`fit_10mpa.png`：数值表和对比图。
- `src/wheeled_tasks/chassis/gas_spring.py`：Torch 力与势能函数，要求显式安装基准。

在训练仓库根目录运行：

```bash
python tools/fit_bkb_gas_spring.py
PYTHONPATH=src python -m pytest tests/test_gas_spring.py
```

势能按 `U(s)=S*(280u + 122.735918491u³/3 + 53.969804409u⁴/4)` 积分，
测试验证 `dU/ds=F`；后续向物理引擎施力时必须作用于伸缩轴或两端等大反向力，保持内部力守恒。
