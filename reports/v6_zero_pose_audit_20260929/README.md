# V6 编码器零位与初始静载几何核对（2026-09-29）

**结论：现有 offset 经新 V6 符号映射后，确实对应约 105.02°、大腿向上的姿态。初始静载的额外张开并非把 API 零位错误映射到了 110°。初态近零命令可以由上止挡承受气簧反力解释，但仍须独立解释 0.73°～1.98° 的几何超限；这不是已完成的硬件标定。**

本次只读取冻结资产、既有静载 JSON 和 profile，运行本机 NumPy/SciPy 闭链 FK/约束求解、势能差分。没有硬件动作、训练、GPU 仿真、资产或 runtime 修改；没有使用任何执行器拟合值作为零位、力矩或止挡标定。

- 资产：`model/纯底盘_v6_232mm/urdf`，final_r3 manifest SHA-256 `9542c788afd6e1b7f0af5e396062f123e511f63579cd8807087068e82e401c5c`。脚本逐一验证 manifest 内全部文件哈希；40–110° 原限位不变。
- 几何算法：原封使用 sealed `tools/build_v6_closedchain.py` 的 `closure_error` / `solve_pose` 函数（仅 AST 提取这两个函数，避免导入无关网格依赖），使用 sealed `tools/v6_mechanism.py::fk`。从 nominal 经 60 点主动轴延拓保持装配分支；最大闭链销点残差 `2.95e-14 m`。
- 膝内角：髋→膝及轮轴→膝向量投影到公共转轴法平面后求夹角；没有把膝电机角或两轴差直接当成几何内角。
- Profile 证据：RMCS `docs/zh-cn/artifacts/pair_multiband_v2/pd_loaded_candidate_20260928/profile.yaml:45–54,137–145,178–183`，以及当前 `rmcs_ws/src/rmcs_bringup/config/wheel-leg-infantry-pair-pd-loaded-identification.yaml:44–53,153–158`。其中 API 已做 reversed，各 model_sign 为 +1；注释记录在大腿向上、物理内角 105° 时电机内部设零。冻结候选注释还写了实车止挡 105°，但此条与资产 110° 的物理一致性仍由主任务向用户确认，本报告不擅自改限位。

- 程序：`scripts/audit_v6_encoder_zero.py`；机器可读结果及源 SHA：同目录 `audit.json`。

映射次序（四轴顺序 LH/LK/RH/RK）：

```text
q_old = remainder(model_offset + q_api, 2*pi)
q_v6  = -q_old
model_offset = [-1.6, -2.93, +1.6, +2.93] rad
```

这里的 `q_api=0` 指驱动 API 角度为零；不能再把 `api_motor_reversed=true` 重复作用一次。机械 motor-output 到几何内角仍须经过闭链 FK。

### 原静载报告的小诊断偏差

原值左 `106.984633452°` / 右 `105.732472555°` 相对本次 FK 分别为 `+0.000505245°` / `-0.000504275°`。`Replay.state_at` 为闭链切向最后求解了 aux `+1e-5 rad` 扰动，`static_load_audit` 的 `self.audit.inner_angle_deg` 当时读取留在扰动态的 audit.data，而 `q_rad` 是原始 full。因此小差异是诊断 getter 状态，不是物理偏差；对上述 0.73°～1.98° 结论无实质影响。已通知主任务修正，不在本任务修改拟合脚本。

## 4. 上止挡假设的力度与边界

本次对 final_r3 的 CAD 质量重力势能及固定名义气簧曲线沿闭链做中央差分，重力取原报告 `[0,0,-9.81]`。这是模型条件计算，不是实测弹簧力；未采用拟合 armature/damping/friction/lag/gain。

| 量 | 左腿两轴 | 右腿两轴 |
|---|---:|---:|
| 名义重力保持力矩 (Nm) | +0.570342, -0.910429 | -1.326810, +0.472657 |
| 名义气簧保持力矩 (Nm) | +11.941171, -11.941183 | -12.048291, +12.048252 |
| 合计保持力矩 (Nm) | +12.511513, -12.851612 | -13.375101, +12.520909 |
| `dβ/dq` (rad/rad) | -0.881818, +0.881819 | +0.880129, -0.880126 |

将“名义保持力矩 − 记录提交命令”投影到 `Jβᵀ λ`：

- 左腿 `λ=-14.381715 Nm`，右腿 `λ=-14.716460 Nm`；负号代表阻止膝内角继续增大的反力，方向符合上止挡。
- 电机等效反力约左 `[+12.682,-12.682] Nm`、右 `[-12.952,+12.952] Nm`，即主要是等大反向。
- 理想膝止挡不能解释的剩余同向分量每轴约左 `-0.20657 Nm`、右 `-0.47099 Nm`。小的关节静摩擦、支架/线束反力、非水平重力或模型误差均可能参与；本次没有辨识或确认其中任何一项。

所以，**上止挡能自然承受很大一部分名义气簧反力，近零电机命令并不意味着气簧变弱或两电机真实力矩增益异常**。反过来，这个投影只是方向一致，不能证明接触确实发生。

必须保留三个互斥/待核对条件：

1. 若真实止挡精确为 105°，零位映射准确且连杆刚性几何正确，那么相同装配分支的实际内角不应达到 105.73°/106.98°。必须检查标定姿态是否精确、设零是否保持、左右独立偏置、链传动间隙/弹性、止挡接触处变形、角度测量定义或其他几何差异；当前数字不能同时证明这些前提全部成立。
2. 若真实上止挡高于 105°或没有接触，那么“上止挡承力”解释不足，仍需核对安装气簧真实曲线/压力、静摩擦、夹具约束、真实提交/执行力矩及参考端。不能只凭这段静载指定力曲线缩放。
3. 当前资产上限 110°不会改变同一 q 的 FK，因此不是这次内角差的计算来源。若最终确认改为 105°，应另建有来源的候选资产并审计超限录包，而不是简单改上限后让已有初态被约束拉回，同时把这当作标定完成。
