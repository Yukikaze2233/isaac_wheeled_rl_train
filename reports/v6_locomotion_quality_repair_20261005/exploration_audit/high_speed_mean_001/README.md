# 封存25000模型：高速、旋转与松杆原生回放

本次固定回放已暴露高姿态欠速、方向保持与接触终止问题；没有取得高速平动的完整停车证据。静止速度和姿态成本有真实支付，不能将这些问题解释成相应奖励完全未启用。回放只用于诊断，新增正式PPO更新为0，qualification=null，hardware_ready=false。

模型是累计消费25000的不可变PT，SHA `c4586d5360fe5abe7631a1b4db551dc01bd915b5c908abf49323e26683f0318e`；对应speed域actor4685、本轮修复actor1122。它不是稍后实时1285模型，更不是本轮1500更新终点。完整输入四文件在 `probe/v14_update25000_input/` 已认证。

诊断源码冻结于 `40826af3c46b32bffd6b16f6817715b63ed1c236`，72份实际源码文件和12份b4核心文件通过认证；正式Kaiser仍运行冻结b4源码，未热改或重启。原生actor张量在回放前后不变，没有创建或更新优化器。运行1600次50Hz策略步、6400次200Hz新反馈物理PD；每策略步解码一次、刷新四次反馈与PD，原机械、气簧、重力和轮侧响应保留。

套件 `high_speed_braking_v1` 为16种轨迹×4个初生副本、32秒。轨迹覆盖305/430mm静止，双向3/5m/s，305mm双向1圈/s、430mm双向3圈/s，以及取消后重推。目标采用原生1.5m/s²和4rad/s²斜率；先在305mm原生出生，430mm通过命令升高，无物理状态强写或额外就绪等待。松杆后的目标请求直接归零，可见命令仍走原生斜率。

本次是均值策略及原生信号延迟管线，延迟课程时钟固定于该模型的4685；其他DR、非标准出生与通信丢包关闭，地面采用实读0.5/0.5摩擦。不是完整DR、实测USB时延或硬件资格测试。原生延迟随机抖动的瞬时原始draw没有保留，不能声称该draw逐次覆盖被证明。

首个出生批次固定分母64：failure=7、boundary_truncation=36、timeout=21、success=0、未结束=0。failure与出界分开，timeout只是完成32秒观察，不代表任务成功。首个终止转移计入，其后的继续步进数据不会进入下表。7个failure中4个fall、3个nonwheel_contact。独立流式核验确认36个出界全部为横向位置绝对值超过3.7m，纵向仍在40m范围内；不是纵向跑道耗尽，也不能算成36次摔倒。

上述完整相位统计按200Hz物理帧计权。`summary.json` 同时明确保留完整相位均值和提前终止前的条件均值；只有部分匀速/制动曝光的副本不混入完整相位成绩。305/430静站此处观察13秒，不能与训练TB的完整10秒窗口直接相减。正向3圈/s唯一存活副本51在匀速段的rootLink-Z仅0.22019–0.22243m，可见高度命令恒为0.430m，高度MAE0.209596m；确实降到了低姿态，不能因yaw准确而忽略高度。

后退3m/s、430mm完整匀速段的输出侧轮速度左/右为−32.758/+30.806rad/s，PD目标−33.319/+30.924rad/s；请求或实际轮力矩触及±4.5Nm的占比分别约0.094%/0.125%。轮目标本身偏低，这段没有持续撞力矩上限的证据。后退5m/s、430mm只有部分匀速曝光，不能把它与完整3m/s相位等同，也没有据此确定训练退化的唯一机制。

实际一次计算的reward分项已捕获并按首个出生、相位分析，没有重复计算奖励或额外消耗RNG。305/430mm静止的 `stand_still_lin_vel` 分别支付−0.111/−0.374 reward/s，广域静止成本分别−0.193/−1.652 reward/s。前进5m/s、305mm有0.96 lane-second的部分制动曝光，俯仰floor支付−0.987 reward/s、pitch成本−0.810 reward/s；它不是完整制动窗。后退3m/s、430mm完整匀速段的广域速度成本−2.893 reward/s。因此“完全没有为漂移、欠速或俯仰付费”被实际支付否定；支付存在不保证PPO优势能改善，也没有以这次回放完成唯一根因归因。生产端float32支付重算残差为0；首批JSON double求和最大残差约7.24e−6，全部记录含首次终止后为5.57e−4，均与浮点累加口径区别保留。

纯yaw轨迹使用ordinary模式，正式纯 `rotate_1rps/rotate_3rps` 组也是ordinary；该回放不覆盖 `spin_translate` 的世界参考旋转平移语义与奖励mask。全部记录中首次终止后的巨大负回报仅留作原始审计，不当首批性能或正式训练回报。

原始5.38GB数据压缩保存在 `raw_capture.tar.zst`，逐文件流式解压SHA与manifest全部核对。`archive_receipt.json` 和 `raw_manifest.json` 记录完整保全；大归档与event不进入Git。小型原生报告、首批账本、相位摘要、实际支付分析与独立核验作为结果回执保存。

支付曲线已上传Kaiser原有6006服务，run别名 `v6-native-high-speed-mean-payment-25000-20261005`；上传SHA及别名核对见 `tensorboard_upload_receipt.json`。未启动本机TensorBoard，没有占用或停止6007/6009，也没有打断正式PPO。
