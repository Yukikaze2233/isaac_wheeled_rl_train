## 2. 实际控制链与已证实覆盖缺口

冻结代码链为：**几何 reset → 可选初态零主动矩释放 → SELECT / 插值脚本 → 固定200 ms线性力矩BLEND → 纯RL → 连续1 s传感器稳定门解锁运动 → 真值接稳与后续任务完成**。短暂零主动矩在脚本之前，不是脚本结束后另加释放段；物理重力、气簧和接触一直存在。

- `recovery_training.py:164–176` 写完整关节/root几何，初速度强制为0；`226–237` 在初始释放结束后开始FSM。
- `293–335` 用脚本PD与actor力矩混合，并保存实际有效动作历史；脚本、释放、BLEND区间不进actor更新，actor造成的终止仍保留学习资格。
- `337–366` 分别维护物理真值接稳、首次解锁和后续任务计时；不允许运动释放后的表现补造释放之前缺失的1 s稳定证据。
- 全链真值还要求双轮接触、无非轮接触、正确平台、姿态/高度达标和后续命令连续完成。普通台阶的“接管后失败”可能是平台或下一台阶事件，不能全部记成接稳失败。

最新累计快照的**26个 `followup == 'forward'` 组**，实发vx命令均值与方差都是0；这不是组名含`forward`的31组。说明所观察任务还未实际执行解锁后的前进命令。此时“后续前进跟踪失败”没有对应输入，下一实验应先定位连续稳定门和物理真值门。

逐门训练读数提示轮速、腿速、gyro及支撑门经常不满足，但该点分母是当前holding人口2243，稳定峰/打断次数又是全4096人口均值。它是既有父审计转述的TB点，本审计未重新读取event；不能把相关的边际通过率相乘，也不能据此指定唯一根因。

## 4. 奖励支付与复习：事实和假设分开

接稳成本在完整actor-owned区间真实支付，公式为广域pseudo-Huber负成本加Gaussian精核负成本；零误差为0，广域项持续区分较大误差。姿态/角速度全actor区间生效，腿速/轮速只在motion_hold生效，yaw解锁后跟随可见命令。环境仅在汇总时乘一次policy_dt，成功/失败事件分别一次性计+30/−200。009c记录真实负组件，例如姿态广域最小−0.478、角速度广域−3.765、hold轮速广域−0.319；确认启用，不证明权重最优或PPO一定学到。

v8不是没有复习：54恢复组占65%，完整旧平地41组占35%；所查原生有效rollout中平地34776/88557≈39.27%。旧平地覆盖静止、升降、±0.5/1 m/s、启停/速度曲线和双向yaw，**不等于覆盖v14当前高速×高度混采、松杆停车、L1静止成本和姿态floor**。
