## 修复有效，但不足以恢复能力

TensorBoard的32个普通行为落地高度／速度奖励tag在40次更新中全部严格为0，确认错付通道关闭。相位占用不是付费掩码：230mm最后5批仍有17.36%的RECOVERY，不能用低LANDING比例声称恢复相位消失，也不能仅以比例下降证明行为因果。

230mm相对未修复对照有实际改善：高度误差约7.0→4.2mm，失败项由高度／速度／漂移／静止速度缩为漂移。但其漂移仍高于A；350mm基本不变，250mm漂移更大，380mm仅一个评测seed过线。高度也不是全线改善：380mm约0.61→1.01mm，height_scan约3.92→4.33mm，230mm前进约10.02→10.75mm。

相对A双seed通过集合，本轮无新增通过，失去`stand_230mm/350mm/380mm`、`forward_05_height_230mm`及`rotate_1__link_combined/link_jitter`。后两个是相对未修复接续新增的失败，yaw约0.153rad/s。因此证据只支持“该激励漏洞真实且修复生效，单独修复不足以恢复整体表现”；尚不能完整排出其与其他缺陷的因果重要性。

## 尚未解决的采样问题

- 1,333个停车环境仍相位同步，40批只有7批含制动、14批含驻停，最后5批均无这两个窗口。这是优先检验的结构性缺口，尚不是经干预证明的停车根因。
- 每个worker仅演进19.2s，静站20s／扫描28s未完成一整个回合；恢复优化器不恢复场景和命令历史。下一轮不能继续把短评测间隔等同于销毁场景。
- 九静站档每批仍有460–528环境，230档40批有441,600转移。没有证据仅凭约2.5%份额认定静站训练不足。明确缺少的是低／高姿态与行走、yaw、停车的联合覆盖；它不直接解释350／380mm纯静站回归。

## 建议边界（尚未实施）

倾向有界修复而非按现状晋级。保留A学习状态作起点候选、保留已验证落地修复和fixed LR；预算继续从778记账，不退款。
